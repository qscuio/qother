# 地球往事：文稿编辑

先判断读者要读懂什么，再整理页面。排版不能替代重写；读者不该在旁白、来源和镜头参数之间反复切换。

## 看完整套材料

读主稿及其链接的事实、制作与结构化文件，确认各自用途。保留系列语气、事实边界、标题与关键标识之间的关系。编辑普通大纲时以内容层级为主，不强制采用分集脚本布局。

针对具体问题选择改动：难读可能来自解释顺序、句子负担、重复、标题碎片化或制作信息侵入；不要只换同义词或加粗标题。若要改变故事逻辑，结合 `$earthstory-scriptwriting`，并核对改动后的事实含义。

## 两个阅读层

主稿 `script.md` 是完整连续旁白。用一个一级标题、简短导读和少量二级故事标题；常规单集可试 6—8 段，但让内容决定。段内自然分段，不给每句建标题。不用表格装旁白，不用整段加粗、重复分隔线、装饰性图标或密集标签制造层次。

制作／核查资料是查阅层。保留镜头、画面、来源、计时、风险和状态，必要时用紧凑表格。主稿在开头或结尾集中链接它们；学术来源不逐句打断旁白，但涉及模型与不确定性的口语限定必须留在旁白中。

已有镜号和来源 ID 不重用、不悄悄重新编号。重排内容后在伴随文件中记录“主稿标题或段落定位 → 原镜号／主张 → 来源 ID”。旧镜头网格如果暂未重排，明确标作旧比较基线，不能让文档声称它已与新稿逐字同步。维护现有机器可读文件或明确记录其待同步状态。

## 编辑顺序

大幅内容修改先做定位到句段的诊断，再重写；不要在诊断报告里先塞入完整替代稿，掩盖问题本身。具体方法见 [叙事方法](../../../docs/writing/narrative-craft.md)。

- 结构：每段是否推进问题，标题是否说出这一段真正的变化；删掉抢先讲完下一集的枝节。
- 意义：合并重复，修复因果缺口，分开过载的句子。增删修辞后仍须检查是否增加事实、夸大确定性或抹去必要限定。
- 口耳：检查主语、代词、术语首次解释与朗读停顿。中文不按英文单词上限裁切。保留有用的自然节奏，别把所有句子剪成同样短。
- 页面：用空行和稳定标题层级组织段落。检查渲染后的 Markdown；无预览时明确只做了文本检查。核验相对链接、段落锚点、标题及文件名。
- 一致性：对照来源和版本；更新计时的“估算／试读”标签、主稿与分镜适配状态，不篡改未实际运行的验收结果。

按 [共同验收标准](../../../docs/writing/editorial-rubric.md) 给出简短前后对照；保留事实硬门槛和未解决问题。无需给读者附上冗长编辑流水账。研究来源与取舍见 [研究索引](../../../docs/writing/research-index.md)。
