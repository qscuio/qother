# 博物志铜版图谱

先读[共享流程](../../../docs/style-system.md)、[当前制作配置](../../../docs/production-style.md)和[分镜契约](../../../docs/storyboard-template.md)。状态 proposed-unvalidated：仅比较/方案，不自动选定、不代表已安装渲染器或部署 agent。冻结脚本不改写；视频前必须同时批准同版分镜与构图关键帧。

完整原始男性主持人仍用当前右下圆形角标，场景铺满画面，不挖空侧栏或底栏。现成男性标准普通话须实际试听；本次未启用克隆，另行授权可再评估。原始角色及私人录音不进入公开方法包。字幕遵循屏幕层可读性，不照搬上游手写小字、装饰栏和女声。

## 可执行视觉语法
- 色板：纸 #F1E8D2、墨 #241D17；以纸的留白为亮部、线密度为暗部。局部淡彩从赭 #B58B48、灰绿 #70816B、灰蓝 #7F9297 中选一个有说明用途的强调色；灰蓝只能是对象局部颜料，不能扩成背景。色素未知时保持单色或明确标注艺术推测。
- 材质：细长纤维、极弱压痕固定到图版坐标；不用全屏棕色滤镜冒充版画。排线沿壳体、生物肢节或器物曲面弯曲，线头尾细、中段稍粗；亮部单组疏线、暗部交叉线，不在黑线层用整片灰色填充。
- 缩放规则：排线间距按对象高度建立，缩小后若变灰或闪烁，减少细线而非增强锐化。淡彩在墨线下，半透明、轻微边缘积色；不得盖掉化石关键形态、比例尺或文字。
- 字体：中文标题用已授权可用宋体/衬线，中文标注和字幕用同一清楚正文体系；学名拉丁文按分类惯例使用斜体，编号用端正数字。1080p标题48–60 px、标签30–36 px作为起点；不照搬上游15–19 px小标签或花体字幕。字体未确认可用时先交字体类别，不下载文件。
- 构图：一个主标本，最多两个相关细节窗；编号与引线对应，所有放大窗标倍率或比例尺。轮廓/细节窗/说明之间要有可辨留白，整幅场景依然满幅，不为主持人或字幕开整条空栏；拒绝把许多微小物种排成不可读壁纸。
- 形态：化石、推测软组织、活体复原分别标明；推测轮廓用另一种线型及文字。不能仅凭美术对称性补齐未知器官；各图版的地质年代/地域和体型依据必须匹配。
- 灯光：统一左上虚拟光向，只控制排线密度与轮廓轻重；不加塑料高光、浮雕阴影或真实动物皮肤。铜版压痕只是一条轻材质提示，不强迫出现工作台。
- 摄影：像放大镜阅读图版，先定位再推进细节；图版坐标和引线同步运动，字幕与主持人保持屏幕层。读标签阶段固定，或极慢推进；新出现的标签读完前不裁出画外。
- 动作：轮廓 → 顺形排线 → 暗部交叉 → 相关细节 → 局部淡彩。主要对象首帧已有可辨轮廓，避免先等数秒空纸。显影表示观察/解释，不表示生物在真实时间长出器官。
- 转场：同一形态特征匹配切、图版替换或局部擦除后重绘；新年代出现时明确标记。翻页只在“图册”叙事确实成立时使用，不套所有镜头。
- 禁区：均匀矢量线假装铜版、纹理盖过证据、物种混时、未知颜色当事实、伪造历史版画出处/签名、装饰比例尺、淡彩使未知组织看似真实。

## 检查与交付
交主图/细节窗方案、形态证据和推测说明、对应比例尺、候选图版及共享storyboard；查缩小后排线摩尔纹、墨线与文字碰撞、放大倍率和标签顺序。未实际渲染/播放的视觉或动态验收标 not-run。该风格不改变已冻结叙述或当前主持人。
