# 设计与静帧门槛

以下是本项目的工作检查法，不是外部设计体系认证，也不是固定风格。

## 八项可观察检查

1. **信息层次**：先说清主体、关系、环境各是什么。缩到25%看主注意点，再回原尺寸看解释细节。静帧不必独自证明全过程，但应能辨认过程涉及的对象；状态对照或三帧必须提供具体增量。好看的噪声不能算机制。
2. **构图与留白**：主事件有清晰轮廓；负空间给视线、关系线和文字，不是把主体缩成角落小图。避免屏幕均匀铺满等重要元素。必要比较可以对称，物理网格可以存在，前提是结构对应实际信息。重要端点不可被边框或字幕裁掉。
3. **字体与中文字幕**：明确标题、对象标签、字幕各自角色；通常一套可靠中文字体加必要数字字体就够，字体授权/缺字需检查。字幕按语义断行，通常一至两行；禁止截断专名和让标点孤悬。用真实长句、中文标点及数字测试，不用 lorem ipsum。以最终播放尺寸检查字形和笔画；别把1080p像素字号直接当手机阅读结论。字幕区遵循本次平台/项目安全区，避开证据；如底部15%基线不适合，先明确说明调整原因。
4. **颜色与对比**：先定义颜色表示的对象/材质/阶段/物理量，保持跨帧意义。蓝色和黄色都可合理使用，灰黑也可能造成无层次；不从一次反馈推导永久黑名单。灰度检查主体边界与文字，意义不能只靠红绿差别。参考WCAG文字4.5:1与大字3:1作合成自检，但这是借用的可读性指标，并非视频认证；检查文字实际背后的最差背景状态，描边/底片也须实看。
5. **三维空间**：要求真3D时保留可追溯场景/相机设置，实际图像应支持前中后层、透视与正确遮挡；移机时应有符合深度的视差。景深模糊可选，不能糊掉证据；不能用阴影、倾斜卡片或整体缩放伪装空间。固定机位可以合格，不为证明3D强加摇镜。空间透视的视觉可信不等于物理尺度已校准。
6. **物理对象与标注**：先看懂对象，再用少量锚定标签说明。标签避让对象和彼此，连接线端点明确，遮挡关系正确。颜色、箭头、轨迹和光圈须有语义；不用装饰性读数制造测量感。示意点不随意画成恒星；网格/地面应说明是坐标示意而非宇宙外壳。膨胀示意选定的参考点不是宇宙中心，尺度变化也不能被相机拉远冒充。
7. **运动与注意力**：分别写物体运动和摄影运动的目的。建立对象→显示变化→给阅读停顿是可用顺序，不是固定秒数模板。同一关键时刻避免字幕换行、镜头转动、多标签弹出和主变化同时竞争。物理变化按模型，图形强调按阅读需要；不要把UI缓动套到宇宙演化速度上。没有真实播放就不声称节奏已测。
8. **反模板与连续性**：问“换掉标题，这画面是否能原样用于任何产品演示？”若能，找出未受主题约束的结构并重设计，不能只换配色。三帧核对对象身份、可解释的比例变化、光源、视轴、标签锚点、颜色语义与字幕区。随机重生点云、标签换目标、无说明的尺度重置都阻断后续制作。

## 审查顺序与证据

先看无标注版本辨认对象与空间，再看带真实文字的版本；明确二者提供的信息差别。原尺寸检查字与端点，缩略图检查层次，灰度检查对比。记录所见而非“高级/电影感/有质感”。

同镜三帧应使用同一组对象ID/资产版本和可复现时间参数。相机不变时，物体关系变化才可归因于过程；相机变化时，记录怎样排除视觉缩放混淆。静帧系列能揭示连续性风险，不能证明两帧之间无闪烁或文字可读时长足够，之后仍需视频播放验收。

优先修科学误读和解释缺失，再修层次、空间、文字，最后才细调材质。技术渲染成功、视觉合格、用户选定是三个不同状态。只向用户展示已内部复查的候选；不要求用户替制作方逐项找缺陷。
