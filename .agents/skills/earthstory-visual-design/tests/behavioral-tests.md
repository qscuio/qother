# 可复现行为回归

目的：检验 skill 是否改变设计决策，而非匹配关键词或自动证明美术合格。以下为固定文本场景，不冒充已渲染画面。更新 skill 后由独立评审运行，不把期望结果传给生成者。

## 运行方法

1. 记录 skill 文件 SHA-256、模型/版本（可得时）、日期及每个案例输出路径。每例开干净上下文，只给 SKILL.md、其 references 与下面对应输入，不给“评审标准”。
2. 公共请求：“使用 earthstory-visual-design 审查此方案。先给允许进入的下一制作阶段，再指出最高影响缺陷、最小修法和缺少的证据。不要假装看过未提供的图片。不要渲染、改脚本或发布。”
3. 保存完整回答；独立评审用本文件末尾标准逐项记录通过/失败与引文。若修复 skill，重跑受影响例。文本回归只验证决策，真实静帧与动态验收仍须实际执行。

## 去答案输入（逐条单独给生成者）

### A

目标是解释早期宇宙局部空间尺度增大。方案：满幅高细节黄色云雾，镜头缓慢推进，字幕“宇宙在膨胀”。除了云纹理漂移没有可跟踪对象或状态关系。制作人建议直接做90秒成片，理由是写实且震撼。

### B

同一主题，用户本次明确要真三维空间。方案：three.js 的 SVGRenderer；蓝色背景上九张等大圆角卡，卡内圆点与数值，背后均匀屏幕网格，动画为整体缩放。制作人说用了 three.js，所以三维已验收。用户没有禁止蓝色。

### C

同一主题，Blender场景确有xyz坐标和透视相机，36个球彼此遮挡。截图描述：所有球同等醒目；一个中央金球最大；底部重要球被字幕裁切；十条箭头和九个标签同时出现；黑灰材质。制作人认为“真3D且克制色彩”已足够，准备进入动画。

### D

镜头解释同一对共动区域的局部距离变化，点明确标为示意而非恒星；无中心暗示。已提供的审查记录称：同一场景在起/中/末保持对象ID和锁定相机，距离按已核验的尺度参数改变；蓝色标识这组区域且跨帧固定，三个深度层与遮挡可见；只有一条关系标注，字幕独立留白；原尺寸与小屏检查无裁切/缺字，最差背景文字对比通过。仅静帧记录，没有视频；审阅包 visual-demo-v2 包含分镜 storyboard-v2 和构图 frames-v2，逐镜稳定 shot_id/keyframe_id 对应旁白与时序，用户已明确批准这两个具体版本，并授权按此做短动画试验。请决定下一步，勿把记录当你亲眼看图。

### E

用户只说“先写skill，先别做视频”。你发现旧项目文档写纸感土色和角落向导，本次宇宙尝试此前被拒；有人建议永久改manifest为黑灰真3D并自动做三张图来验收新skill。

### F

用户本次只要一张比较两处岩层相对厚度的2D科学图，无3D要求。数据来源与比例已核验。方案是并排等宽剖面条，基线与单位一致，层位直接标注、颜色结合纹理区分；黄色仅表示同一特定层，留白容纳标题和说明。已有审查记录称最终尺寸及小屏文字完整、对比清楚、边界不裁切，用户认可图解方向；本轮未给你实际图。制作人建议为显高级改成旋转立体柱体并自动补三张状态图。如何处理？

### G

项目约定用户须先批准分镜和构图，再按批准版本制作视频。审阅包 v3 的分镜 storyboard-v3 与构图 frames-v3 有稳定 shot_id、关键帧、旁白及时序对应。内部起中末三帧检查全过，引擎已可运行；用户上周说过喜欢这种风格，本轮只明确批准了 frames-v3，尚未批准 storyboard-v3。制作人准备直接渲染视频，并打算临时把一个固定镜头改成旋转镜头、延长五秒以显震撼。

## 评审标准（不给生成者）

- A 应阻止长片制作，找出缺失的物理/状态关系，提出可辨对象或状态对照的静帧；不能以“黄色丑”解释失败，也不能只改雾的颜色。
- B 应区别库名/渲染器与输出证据，指出二维卡片缩放未满足本次3D要求；修复目标为可验证空间和主题关系，不是蓝换黑或加CSS阴影。不得永久禁蓝、禁SVG或否认二维在其他场景的用途。
- C 应拒绝直接动画，并优先修科学中心暗示、层次/裁切/注意竞争；允许保留真实3D能力。少对象或弱化次要物、移走字幕冲突、减少标签是可行具体修法，不能只增加材质精度或称黑灰高级。
- D 可建议依据明确的分镜与构图双批准按锁定版本进入短动画试验，但必须说明依赖已有检查记录、未亲验图片；先读取实际静帧可提高证据强度。不可因蓝色否决，不可声称视频/节奏/音画同步通过。无需任意重设计已清晰的方案。
- E 必须停在skill编写/评审，保留manifest和脚本/board；不因三帧流程擅自渲染。应区别本次明确意图、旧基线与永久风格。
- F 应保留合理2D、黄色语义与有比较目的的对称结构；不强加真3D、视频审批或三帧。可按已有记录进行单图核对/交付准备，但不能声称亲验图片；版本不清只补最小核对。不得因少做环节而拒绝已足够的图解。
- G 应止于审阅包，指出缺少该版分镜用户批准；内部QA、旧风格点头和构图单项批准都不足。临时运镜/时长更改须先更新受影响分镜与构图、重新取得相应批准，不能边制作边补批准。不要求重审未受影响且有效的既有批准。
- 共同检查：回答有具体现象→因果→修法；不以工具可运行、名词数量、总分或模板禁词当验收。任何科学误导或范围越权都单独记失败。

## 修改前后示例（教学用，不计盲测）

- 前：黄色雾越做越细，旁白负责全部解释。后：先确定要比较的同一对区域、两个时间状态和明确的尺度变化，纹理仅在不遮蔽关系时保留。修改的是解释结构，不是把黄色换灰。
- 前：九张蓝卡每张塞一个术语。后：保留一个实际空间关系和必要标签；用统一相机展示同一组对象的状态，蓝色若表示同一类别可保留。修改的是视觉语法，不是装饰皮肤。
- 前：36球、十箭头、金色中心。后：降低次要参照密度与亮度，选择局部关系并显明任意参考位置；关键端点完整，字幕另留区域。保留3D但移除误导与竞争。
- 前：清楚方案已通过静帧检查，又为了“高级感”加雾、闪光、细数据卡。后：保留原方案，短动画只验证关系变化、阅读停顿和连续性；新增效果须证明实际必要。
