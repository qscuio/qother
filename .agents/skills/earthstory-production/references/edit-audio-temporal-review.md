# 剪辑来源、声音事件与连续帧复核

适用：剪切/变速已有旁白或素材、叠加声音事件、程序动画进入最终封装之前。沿用既有 cue/shot_id、统一时间线和逐镜缓存；本文补充 review sidecar，不改变 storyboard v1 或运行中的渲染任务。普通确定性和四类验收仍见 cinematography 的 determinism-and-qa.md。

## 来源到成片的映射

剪辑记录需要同时保留原素材哈希、原素材时间区间、输出帧区间和速度。恒速片段的源时间是 source_in + (output_time - output_in) × rate；不要把输出时长直接当成消耗源时长。区间采用半开边界，输出帧以有理 fps 换算，避免 30000/1001 被误写成 30。变速曲线需明确积分映射；不支持的曲线不能冒充恒速。

字幕引用保留词/句的原始区间及片段 ID，然后由同一映射得出输出区间。剪切跨过一个词时先标记复核，不把断词自动算合格；复制、重排和有意重叠要有明确依据。字幕不必覆盖无声段；完整性应针对声明需要保留的内容，不能要求每一帧都有字幕。来源对应正确只证明元数据一致，不证明说话内容真实、素材有授权或观众听得清。

新增侧车校验器及示例见仓库 scripts/validate_review_sidecar.py 和 examples/review-sidecar.valid.json（以实际交付接口说明为准）。它与原生产文件并行保存，不能直接作为渲染器输入；结构通过之后仍须查看真实导出。

## 声音事件与混音

- 每个事件引用 cue/shot_id，区分画面事件时刻、源音频瞬态位置、片段入点、修剪量、速率和尾音。素材开头有静音时，调整入点或修剪，不移动已正确的画面。全片起点改动后重新推导事件，不复制散落秒数。
- 旁白、音乐和音效分角色。音乐的旁白侧链不能包含自身或音效；多段旁白应由角色组解析，避免新增一句话未被混音包络覆盖。包络必须注明片段局部时间还是全片时间；效果顺序和尾音长度也进入证据。
- 在实际交付文件测预期事件附近的局部包络，记录窗口、阈值、预期/观测 onset、偏差帧数和证据。100ms 只可作粗扫描候选，短瞬态/音素要更细采样。旁白峰值可掩盖缺失音效，因此需独立音轨或 cue-muted 差分与核听；不能靠总混音峰值确认某个声音。
- 峰值、响度、起音、尾音截断分别检查；普通采样峰值不是 true peak。没有原声或可用静音参考时，不根据单段未知人声频谱武断“修正音色”。素材未实际分析就记录 not-run，不伪造测量或 ASR 对齐。

## 连续帧与切点

先标出有意切点、闪光、停顿和 on-twos 风格，再扫描异常。单帧亮度/差分尖峰、短冻结、边界跳动是复核候选，不是自动美术裁决。噪声、粒子和有意闪光可能误报；相邻图像差的平均幅度不是运动方向，也不能证明速度连续。

运动模糊子帧必须限制在当前镜头的同一侧：不得把切点后的物体混入前一帧。以切前最后有效帧、切后第一帧及对应子采样时间作测试；最终 hold 要同时检查进入 hold、最后有效帧和导出结尾。仅循环素材比较首帧与一个完整周期时刻，普通叙事镜头不要求首尾相同。

主体运动证据观察真实主体而非辅助框：关键姿态、跨遮挡/深度关系、中途最拥挤帧、文字真正可读的停留区间。运动拖影与逐帧 strip 各有用途；canvas/WebGL 内部运动不能靠 DOM 包围框证明。声明的角色锚点需要真实像素复核，不能把代码坐标当检测结果。

## 执行边界

新增结构校验可以在不安装库的情况下运行。音频/像素扫描、实际帧捕获和渲染适配器必须有实现与真实 fixture 后分别报告，不能由本文推定已完成。所有固定阈值均由镜头目标和实测校准；不要强制广告节拍、持续运动、同一配色或所有文字统一阅读速度。

来源与许可、逐仓库读取深度及不采用的内容见 docs/shared-motion-resources-audit.md。这里为项目独立整合的方法摘要，未复制上游实现或素材。
