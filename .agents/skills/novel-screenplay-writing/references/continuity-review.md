# 长项目：状态、续写与有边界的审校

## 从真实材料恢复

打开项目目录或用户提供的文件，定位当前版本、最近正文和本次相关章节。先读原文，再用记录辅助检索。若记录与正文冲突，查清版本和作者决定，不把摘要默认当权威。无法访问的文件、缺失前文和过时记录明确列为缺口；不要凭“上次记得”补全。

只为长项目维护必要记录。下面是可选的轻量文件布局，不要求已有项目迁移，也不为短片段建库：

- `project.md`：作者目标、类型/视角/语气、不可更改项、文件位置、最近工作点。
- `canon.md`：实体、已确立事实及来源；人物动机、知识与状态要带时间/场景范围。
- `outline.md`：候选方案、计划章节/场景及目标，明确尚未成为正文。
- `drafts/`、`final/`：按实际工作方式区分草稿与作者确认版本；目录名本身不构成验收。
- `handoff.md`：读过/改过的版本、实际保存路径、未解决问题、下一步、需复查的下游范围。

这些是人工维护的文本记录，不是自动同步的数据库。只报告实际完成的读取、写入与复核；未经检查不能声称“全部设定已同步”。不能写文件时给出简短可复制记录，不伪造路径或保存成功。

## 来源与稳定标识

沿用现有 ID；新项目可用 `CHAR-001`、`LOC-001`、`SC-001` 等稳定标识。改名、别名与章节重排不更换实体身份。只有同名不能认定同一人，省略名字不能认定此人不存在；人数约束要核对实体、别名及出场范围。

事实记录只保存有用字段，例如：

```text
CHAR-001 | 林禾 | 别名：小禾
事实：在 SC-004 结束前不知道父亲已离城
来源：drafts/ch02.md，v3，SC-004，第 3 段
层级：草稿事实；尚未被作者确认
状态：当前；适用范围 SC-001 至 SC-004
```

区分证据层级，不互相偷换：

1. **作者明确决定**：权威约束，保留原话或准确摘要及出处；后来明确修改可取代旧决定。
2. **计划/候选**：拟发生的事，不证明已发生、人物已知道或伏笔已回收。
3. **草稿事实**：当前文本实际发生的事；可待修订。
4. **确认版本事实**：作者认可版本中的事实；冲突时显示来源并处理，不静默改写作者意图。

角色还应区分“世界中为真”“角色知道”“角色相信但可能错”“读者已知”。知识获取要有信息来源和时点；角色可能撒谎、不可靠叙述可能有意误导，不把所有差异当错误。伏笔记录植入位置、可用解释、计划回收与实际回收证据；计划回收不等于已回收。

修改早期章节后，标记依赖该事实的后续状态、摘要、伏笔及审校结论为 **stale/待重检**，记录影响范围。只更新实际复核过的条目；无法完整重查时交付已修部分与未复核范围，不声称全书一致。

## 先冻结目标，再判断文本

在写作或审校前从本次请求及作者已定内容提取少量可验证目标，给稳定 ID，注明必需/可选、适用范围与来源。不要为了让稿件通过而事后换目标；合理变更要记录旧目标、变更理由及作者依据。审美偏好可以是作者目标，但不能假装成普遍客观规律。

对每个目标作三态判断，并附具体证据位置：

| 状态 | 判断依据 |
| --- | --- |
| completed / 已完成 | 当前适用版本中的证据足够支持目标，相关限制也已核对 |
| unmet / 未满足 | 有明确矛盾、反例，或已完整检查相关范围后确认所要求事件未发生 |
| unknown / 未知 | 缺材料、版本不明、范围未完整检查、信息含糊或证据不足 |

“记录里没提到”本身只能得到 unknown，不能推断达标或不达标。例如只读第二章没见约定的告别，不足以断定全篇没有告别；完整核对目标指定场景后发现角色径直离开且无告别，才可判 unmet。目标为“不得泄露秘密”时也不能用一条未提及秘密的摘要证明满足，需检查相关文本。

存在必需目标的 unmet 或 unknown 时可以交付草稿、修订稿或局部结果，但不能称“全部验收通过”“确认终稿”。技术检查通过也不等于作者认可；没有作者认可时标为待作者确认，而非自行制造认可。

## 分开诊断、修订与验收

1. **检查**：给出位置、问题、影响及证据。客观连续性/因果问题与可选审美意见分列；重大程度由对本次目标的影响决定，不由偏好决定。
2. **修订**：优先最小有效修改，保留作者声音、已成立情节和授权边界。局部修复无需每处请求批准；需要改动核心前提、删除整条支线等超出范围的取舍，先提案。
3. **比较**：有文件时看实际 diff；无文件时比较修改前后关键片段。若文本未改变，明确 no-op/未作修改及原因，不能称“已经修好”。仅改标点不能宣称因果缺陷已解决。
4. **复核**：重查被改目标与直接受影响的前后文；保留未改目标及证据。默认一轮检查、一轮针对性修订、一次复核；若仍有关键问题，只在范围明确且能修复时继续。停在已满足本次请求、剩余问题需作者决策或材料不足的位置，说明待决项，而非无限自评循环。

长项目交接精简列出：交付文件/版本、关键改变、目标三态、仍待处理项及受影响但未复核的范围。短修订只需正文和必要的一两句说明，不输出全套审校表。
