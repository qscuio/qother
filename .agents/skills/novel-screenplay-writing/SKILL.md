# 小说与剧本创作

交付能读的小说或能演的剧本，不用策划表代替用户要的作品。保留作者选定的前提、类型、视角、时态、语气和篇幅；不擅自改成更商业、更励志或更悬疑的故事。

## 先确定交付，不扩大任务

从请求和现有材料判断：**小说 / 剧本**，**构思 / 写作 / 续写 / 修订**，**短作 / 长项目**。只问真正阻碍执行的问题。短场景、试写、单段润色直接交付，缺省选择可在必要时简短说明；不先索要完整人物小传、世界观或多轮确认。用户只要提纲时不擅自写整章，只要正文时不先展示一套工序。

- 小说：读 [小说技法](references/fiction-craft.md)，产出有叙述视角、具体行动与语言质感的正文。
- 剧本：读 [剧本路线](references/screenplay.md)，产出场景、可表演动作、对白及必要转场，不把剧情梗概分行冒充剧本。
- 多章续写、连续性检查、重要修订：另读 [状态与审校](references/continuity-review.md)。小修只使用与之相关的规则，不创建庞大资料库。
- 科幻/奇幻机制、神话改编或长篇/连载情节设计：按需读 [机制与长线因果](references/speculative-plotting.md) 的相关段落；不把它变成所有短作的前置问卷。
- 需要了解借鉴边界时读 [来源](references/sources.md)；日常写作不需要访问上游项目。

## 按操作工作

**构思**：围绕人物想要什么、为什么此刻行动、遇到什么阻力及选择造成什么后果提出方案。区分作者已定与候选；不强套英雄旅程、三幕节点或每章反转配额。按请求给一句话故事、人物关系、梗概、章节或场景规划。

**写作**：用少量场景意图指导实际正文。人物依据自己知道的事行动，行动引出后果；场景可以改变处境、关系、认知或风险，不要求每场都大起大落。创作授权允许生成新情节，但新写内容仍是草稿，不冒充作者确认的设定。

**续写**：先读取实际提供或可访问的前文、最近结束处和相关设定；核对叙述声音、人物所在地/知识、未完动作及时间。记录摘要不能替代关键原文。缺前文时请求必要片段，或明确交付独立的假设性试写，不声称记得未读章节。

**修订**：先锁定修改范围和保留项，区分客观矛盾与审美建议。做用户授权范围内的编辑，不强迫逐处审批；重大设定变化或范围外重写先提出选择。新解释、新人物、新转折若改变既有设定，标为建议，不静默并入。返回修订稿，并按规模提供关键改动或差异；仅审稿时不覆盖原文。

## 交付与边界

- 作品优先，说明从简。长交付按用户指定目的保存真实文件；无文件工具时交付可复制内容，并明确尚未保存。不声称拥有跨会话记忆、自动状态数据库或持续运行的写作 agent。
- 检查请求的硬约束与实质质量。长项目使用有证据的目标审校；未核实不等于通过。一次针对性修改后复核受影响处，避免为“更好”无限改写。
- 改编以用户提供、可合法使用的材料及允许的范围为界；缺失原文不能自行编造后称忠实改编。参考风格提取节奏、视角、意象等抽象手法，不复制参考文本或提供近似替写。
- 本技能不依赖上游安装、特定后端/API 或付费服务，交付范围是文字而非视频。部署自动 agent、接入外部服务或发布作品属于另外的操作，按用户明确授权执行，不把创作请求当成这些操作的许可。
