# 科学结构图

先读[共享流程](../../../docs/style-system.md)、[当前制作配置](../../../docs/production-style.md)和[分镜契约](../../../docs/storyboard-template.md)。状态 proposed-unvalidated：仅比较/方案，不自动选定、不代表已安装渲染器或部署 agent。冻结脚本不改写；视频前必须同时批准同版分镜与构图关键帧。

完整原始男性主持人仍用当前右下圆形角标，场景铺满画面，不挖空侧栏或底栏。现成男性标准普通话须实际试听；本次未启用克隆，另行授权可再评估。原始角色及私人录音不进入公开方法包。字幕遵循屏幕层可读性，不照搬上游手写小字、装饰栏和女声。

## 适用边界
适合说明板块边界、器物内部、地层关系和有证据支持的结构；宇宙建立镜头、星系空间关系需要真实三维时交回摄影/三维方案。吸收 blueprint 的制图语法，明确放弃其普鲁士蓝底、图纸桌面、签字盖章、整页注释栏和拟人机械表演。

## 可执行视觉语法
- 色板只在审阅时选一套：浅底 #F3F0E7 + 结构线 #292D30，或炭灰 #171A1C + 结构线 #ECE8DE；不使用泛蓝科技背景。局部重点用赭黄 #B67B31（浅底）或 #E2B566（暗底），只标正在解释的对象。未知部分用虚线+文字，不只靠颜色。
- 材质：干净哑光底；纸纹可省略，使用时固定在世界坐标，不能每帧重新随机。没有自发光线框、HUD扫描、漂浮玻璃板或镜面高光。
- 线型：外轮廓/内部结构/标注引线在1080p候选为3/2/1.5 px；中心线长短虚线，隐藏线短虚线，剖切线加方向箭头。移动缩放时保持层级并检查缩小后的断线，不能直接让线宽跟几何同比放大。
- 字体：一套已授权可用中文无衬线，标题中黑、标注常规；数值用等宽数字字形。1080p标注候选30–36 px，字幕40–48 px，以手机缩览验证为准。不存在字体时报告替代，不下载字体或用手写体掩盖中文缺字。
- 构图：主结构占可用画面约60–75%，图例靠所指对象就近布局；最多一个局部放大窗，给尺度条/单位和观测或示意状态留实际位置。剖面切口必须与总览一致；爆炸图分件保留引导轴，不暗示真实空间距离。
- 灯光：本风格以线型和剖面排线说明朝向，不靠3D光照。相邻切面用方向/间距区分，禁止用无来源的明暗伪装材料厚度。
- 摄影：固定正投影，沿结构或作用路径平移；推进放大时保留总览定位或先展示局部框。不得绕行出不存在的背面，不用线图缩放冒充星系间真实穿行。
- 动作：中心/边界 → 主轮廓 → 内部关系 → 剖面 → 标注，先让对象成立再补说明。每次只改变一个解释层；重要标签完整出现后至少留1秒初始读图余量，再按实际文字量和旁白加长。
- 转场：相同结构的总览/局部匹配切、剖切面揭示、同位置版本替换。线条显影是解释动画，不得让观众误读成天体诞生、地层瞬间生成或测量进行中。
- 禁区：蓝底科技模板、假刻度、示意比例冒充真实比例、字幕塞标题栏、箭头把相关性画成因果、随机数字滚动、颜色制造虚假温度。

## 检查与交付
交一镜总览/局部构图方案、线型图例、比例及非比例范围、来源和共享storyboard。检查标签脱锚、引线穿物体、虚线被遮挡后含义变化、剖面位置一致性；没有渲染时动态状态记 not-run。原版参考只提供方法，不能作为科学事实来源。
