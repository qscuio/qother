# Provenance and licensing

The workflow derives from an earlier user-requested paper-and-ink narrated technical explainer. Its successful reusable techniques were original procedural stroke reveals, measured clause audio, stable focal identity, and decoded-frame review. The earlier project was informally called hand-drawn but did not show a drawing hand; this skill uses the more accurate diagram-animation name.

The generic renderer, contract, tests, and queue example were written for this skill. They do not copy third-party animation assets or embed the earlier video's networking facts, voice files, fonts, or model weights. The queue story is invented and explicitly labeled illustrative.

Dependencies are not bundled: Python standard library; Pillow (HPND-style license); FFmpeg/FFprobe (license depends on the installed build and enabled codecs). The optional adapter uses an existing sherpa-onnx runtime and Kokoro model. Verify the exact runtime, model-card terms, voice rights, and installed font license before external distribution. Do not infer a license for a new model/version from this document.

For reproducible deliverables record dependency versions, selected font and its license/source, audio provider/model and voice, timing method, and all reused asset licenses. Do not bundle a font/model merely because it is installed. No copyrighted reference images or source-document excerpts are included in this skill.
