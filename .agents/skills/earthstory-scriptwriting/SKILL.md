# 地球往事：内容与脚本写作

写出值得听、听得懂、读来有滋味的事实叙事。美感来自选材、关系和语言，不靠气氛词替读者宣布感动。默认交付 Markdown；不自行制作 Word、PDF、配音或视频。

## 先判断这次写什么

读本次目标、旧稿与相关来源；完整分集还应读系列大纲、实际前集正文、事实核查和风格约定。区分已讲内容与未来计划，保留授权的年代、范围、目标片长。只改样段时不启动全片生产流程；只优化技能时不改实际作品。

新写或深改先读[非虚构写作手册](../../../docs/writing/narrative-craft.md)，按当前问题选用其中方法，不逐项套用。写出一个简短工作判断：读者原先知道什么；本篇让他理解什么新关系；哪个材料最能承载它；哪些内容暂不讲。题目不是立意，立意也不能预先替证据下结论。

## 从意思到篇章，再到句子

先选证据与中心细节，决定讲述视角和信息次序。让相邻段之间有真实关系，按需要详写关键变化、概述过渡。先写连续旁白，再排镜头；既有十五秒网格只能作比较基线。无须问题式开头、固定三幕、统一段数或每段悬念。

写作或修改时，指出当下阻碍读者的具体问题，再选择最小有效方法：缺少解释就补有依据的机制，次序混乱就重组，意思清楚才做句段精修。保留已经好的文字。语气不确定时，先用同一材料试一小段；有已接受的原创样段才以它定声。操作尺度见[中文改写示例](../../../docs/writing/deslop-examples.md)。

## 事实边界不能靠文采跨过去

区分观测、解释模型和未知，把限定自然放在有关主张附近；只有读者确可能误解时才解释限定本身，不把“这里的约不能删”等编辑提醒念进旁白。不能把先后写成因果、重叠写成整齐阶段、年代界线写成一天。自然过程没有目的；不编人物内心、对白、见证者或感官细节。远古画面在制作层标明示意／模型复原。

类比要有机制对应和适用边界，修辞不能增加事实。新细节先核验；材料不足时标出具体缺口，不用顺口的解释补空白。保留稳定来源 ID 与主张—来源映射；记录主张的合并、移动、删除和新增待核。改写后重新核对因果、数字、条件、范围和确定程度。

## 按范围交付并验证

短样段交付正文与必要的证据／待核说明即可。完整分集交付干净 `script.md`，将来源、画面语义、旧镜号对应、风险及版本状态留在仓库已有伴随文件；不要把制作批注写进旁白。未同步的镜头或数据明确标为待同步，不重用旧 ID。

按[共同验收](../../../docs/writing/editorial-rubric.md)做适用的复述、推断和文本口读检查，报告具体结果。模型模拟不是真人审美证据；未录音就不能称已试音，字数计时只能是估算。先修最高影响的问题，再复核事实；不以禁词、句数或总分验收文学质量。

结构已成立后的局部精修用 `$earthstory-deslop`；阅读稿与制作资料整理用 `$earthstory-document-editing`。方法出处与读取限制见[研究索引](../../../docs/writing/research-index.md)。
