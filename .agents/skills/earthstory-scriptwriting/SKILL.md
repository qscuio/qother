# 地球往事：纪录片写作

写一篇成年人愿意听完、也能顺畅读下去的旁白。让证据支撑叙事，让制作资料留在旁路。默认交付 Markdown；不自行转成 Word、PDF，也不选择或合成配音。

## 开稿前

- 读本集旧稿、事实核查、来源登记、系列大纲和相邻集说明；有现成系列风格规范时一并遵守。缺少材料时说明缺口，不补造系列设定。
- 用几句话定清：本集回答什么问题；从什么状态走到什么变化；观众最后会理解什么；上一集留下什么、下一集接什么。保留原任务的年代、范围与目标片长。
- 新事实先找可靠来源、确认支持范围再写。已有证据也要检查是否支持改写后的因果与确定程度。无法核验的关键主张标记待核，不把它写成定论。

## 先解决内容，再打磨语言

内容开发或深度重写时，读 [叙事方法](../../../docs/writing/narrative-craft.md)。它说明怎样把小说技能的因果、信息顺序、样段定声和分层修订转成事实叙事，及哪些方法不能移植。

面对“难懂、空、像机器写的”稿件，不把换标题、删形容词或缩短句子当成完成。先找出值得讲的中心认识：观众原先把什么想简单了，材料中哪个真实变化能让理解加深？围绕这个认识选择事实，而不是按资料出现的顺序逐条复述。把开头承诺、解释路径和结尾所得连成一条线。

准备一个很短的内容方案：中心认识、最有表现力的具体过程、理解所需的前提、最自然的段落顺序、暂不讲什么。检验相邻段之间的关系能否说清；仅靠“与此同时／接下来／由此可见”连接的两段，往往需要重构。不要给每集强加惊人反转；一个普通过程被准确看懂，本身就可以有力量。

语言的美来自准确的选择、清楚的动作和有变化的节奏。让大小、远近、时间和材料的真实关系形成画面，少用无内容的气氛词。允许朴素、克制的诗意与有用的类比，但不能用漂亮句子掩盖机制缺失，也不能为了顺口删去关键条件。删掉套话后应补上实际解释，而不是把文章剪成干瘪提纲。

例如，只有“漫长的岁月塑造了地球的独特命运”，观众还不知道发生了什么。应回到有来源的变化：哪些物质相遇、碰撞产生什么、内部为何开始分层。具体选哪一个动作开场，取决于本集的核心问题；不把这条示例当成每集的开头模板。

## 先写故事，再排镜头

以一个可理解的现象、处境或变化开场。每一段让观众获得下一步理解：出现什么变化，为什么值得追问，现有证据如何解释，接下来又带来什么问题。选择适合材料的顺序，不套固定三幕，不为每段硬造悬念。

常规 5—8 分钟单集可先试 6—8 个故事段落；这是阅读尺度，不是必须填满的模板。段落可以长短不同。历史场景不能编造对话、人物内心或具体目击；远古过程的视觉化应在制作资料中标作示意或模型复原。

先讲发生的事，再给术语。中文保持成熟、平实、有节奏的口语：一句承载一个主要意思，长短句交替，用具体动词推动过程。清楚说出因果主语，避免让代词跨段漂移。不要把英文词数规则换算成机械字数限制。

避免空泛壮阔、远古谜团、命运注定、无依据的“第一次／唯一／彻底”；避免反复“不是……而是……”来制造没人提出的误解。需要纠错时直说正确机制。不要用重复总结代替结尾的回答。

## 保住证据的边界

- 区分观测或测量结果、主流解释模型、仍有争论的细节；用适量、具体的限定，不把每句都写成“也许”。同类限制不必反复长篇提醒，但新主张仍须单独限定；开场免责声明不能覆盖全片。
- 不能把相邻事件写成因果，把重叠过程写成整齐先后，把年代分界写成单日发生，把研究示意写成已观察到的历史录像。
- 类比必须服务于一个机制；在可能误导之处说明边界，或不用类比。修辞不得偷偷增加材料中没有的事实。
- 在事实核查文件中保留原来源 ID 与稳定的主张—来源映射。删改旁白后同步记录合并、删除、移动及新增待核的主张，不能靠删除引用让风险消失。

## 交付与验收

按请求范围交付。独立短样段、开场或局部改写只需正文与必要的证据／待核说明；不强制导读、小标题、制作文件、镜长或完整评审流程。没有旧稿就不做虚构的前后对照，没有镜头就不配镜；如实说明哪些检查尚未做。以下是完整单集的默认流程，可按任务缩减。

1. 交付干净的 `script.md`：标题、很短的导读、少量有意义的小标题、完整旁白，以及首尾一处制作／证据资料链接。不要每句插入来源、镜号、时间码或镜头指令。
2. 把画面语义、旧镜号与新段落对应、证据、风险和版本状态留在独立伴随文件。使用仓库已有文件名；必要时增加简短制作说明，不破坏已有 ID 或机器可读引用。
3. 朗读或做明确标注的文本口读审查，再估算镜长。保留停顿、图解和视觉独立表达的空间。字数估时只能标“估算”，不能宣称已试音。旧 15 秒网格可作比较基线，不作为新旁白的句段框架。
4. 让初读评审只看正文，定位理解断点并复述关键变化；模型评审明确标作模拟。先诊断后针对性修订，再核对所有改动过的事实、限定与映射。
5. 用 [共同验收标准](../../../docs/writing/editorial-rubric.md) 做前后对照并复查事实；确需验证阅读体验时，让没看制作资料的读者只读主稿，再回答核心问题。报告实际做过的检查和剩余问题。

内容与结构成立后，可用 `$earthstory-deslop` 精修套话、重复和抽象表达；完成后再核事实。需要拆分阅读稿与制作文档时使用 `$earthstory-document-editing`。如需了解本规则的公开研究背景，读 [研究索引](../../../docs/writing/research-index.md)。这些文件是仓库写作约定，不意味着已有运行中的自动化团队。
