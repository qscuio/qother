# 纸感二维历史场景

## 使用范围与状态
历史试制方向，未通过完整成片验收，不再作为宇宙开头默认；仅在明确选择或比较时使用。当前风格状态见共享流程。
本文件是可调用的仓库级制作规范，不是已安装的渲染器、视频模型或运行中的 agent。

## 先读与输出
从本 skill 目录向上三级到仓库根目录。制作时读取 [共享流程](../../../docs/style-system.md) 和 [分镜契约](../../../docs/storyboard-template.md)。检查用户本次选择、事实来源、原始角色素材和实际工具；缺少素材或渲染能力时明确交付的是方案，不冒称成片。
输出本风格的镜头说明、符合共享契约的 storyboard JSON、版本锁定素材清单，以及真实执行过的测试结果。若用户只要求比较，不自动改动已选方向。

## 风格与运动规范
- 色板：纸底 #E9DFC7、深褐 #403A31、土赭 #A8754F、灰绿 #69765A；蓝色保留给原始向导。单镜头至多一种强调色，文字与背景须有清晰对比。
- 材质：统一细纸纹，屏幕空间颗粒密度一致；物体以2–3档平面明暗分层，不混入照片拼贴、塑料高光或写实皮肤。
- 形状/人物：略不规则的剪纸轮廓，圆缓转角；历史人物用同一种简化全身比例、衣料和描边语言。角色必须有完整头颈躯干连接；远景人物简化而不靠换头补表情。
- 场景：前景剪影、中景事件、远景环境三层；事件角色和地貌是主角。以地表剖面、地图或生活场景承载信息，不能只在旁白下轮播静态卡片。
- 灯光：绘制统一左上方的柔和明暗；叠层阴影宽度一致，不把二维素材伪装成真实三维空间。
- 摄影：16:9、正交/平视为主；单镜最多缓慢推近或横移一种主摄影运动。建议4–8秒镜头总推近≤8%，视差相对位移≤画宽3%，避免靠剧烈运动制造“动画感”。
- 动作：必须写出事件主体的起始、过渡和结束状态，例如沉积层累积、地块分离、人物搬运。二维位移采用平滑加减速；停顿保留0.3–0.6秒读图，镜头切换不用无理由弹跳。
- 缺陷禁区：空壳幻灯片、漂浮人物、混搭头嘴、断颈、层间纸纹尺度突变、无叙事理由的缩放、向导遮挡关键事件。

## 项目角色边界
16:9；蓝西装玩具向导使用同一份原始完整角色素材。位置/尺寸与现成男声普通话遵循[当前制作配置](../../../docs/production-style.md)；主持人参考布局不等于整幅构图已获批准。保留头、颈、身体完整连接；没有经过验证的真正绑定前，不拆头、贴嘴、拼异质面部或假装口型同步。实际声音与画面质量单独验收。

## 交付前检查
- 逐镜核对风格、历史依据、主事件动作及可读停顿，区分事实和示意。
- 检查完整角色、向导尺寸、字幕避让、素材版本、镜头连续性与声音状态。
- 运行共享 JSON 验证；它只能检查结构，不代替逐帧视觉检查。
- 有实际渲染时查看首帧、中间帧、末帧及运动中的遮挡/穿模；汇报渲染器、命令、版本、输出规格和未解决缺陷。

## 具体视觉语法
