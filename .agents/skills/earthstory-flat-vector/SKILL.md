# 扁平矢量信息动画

## 使用范围与状态
候选实验方向，未获用户选定，也没有本项目端到端渲染验收。仅在明确要求比较或试验时使用。
本文件是可调用的仓库级制作规范，不是已安装的渲染器、视频模型或运行中的 agent。

## 先读与输出
从本 skill 目录向上三级到仓库根目录。制作时读取 [共享流程](../../../docs/style-system.md) 和 [分镜契约](../../../docs/storyboard-template.md)。检查用户本次选择、事实来源、原始角色素材和实际工具；缺少素材或渲染能力时明确交付的是方案，不冒称成片。
输出本风格的镜头说明、符合共享契约的 storyboard JSON、版本锁定素材清单，以及真实执行过的测试结果。若用户只要求比较，不自动改动已选方向。

## 风格与运动规范
- 色板：暖白 #F5F1E8、墨黑 #27313B、青绿 #397E82、赭黄 #CE9946、砖红 #AD5E50；强调色每镜最多两种，同一概念跨镜头颜色固定。
- 材质：纯色矢量，无纸纹、照片、渐变金属或拟真阴影；轮廓线宽按画面高度固定，放大素材时不随意增粗。
- 形状/人物：圆角几何形、统一弧度和图标透视；人物采用同一套完整简化身体，肢体有明确关节。原始蓝西装向导仍以完整小角标单独保留，不改造成混合图标身体。
- 场景：一个镜头一个主关系（先后、数量、空间或因果）；地图、剖面和图表必须保留比例/示意标注。箭头仅表达已有证据的关系，不能把时间先后画成因果。
- 灯光：平面色块，不做虚假体积灯光。层级通过留白、尺寸、颜色和线条建立。
- 摄影：固定正交画布；用关系展开和受控局部放大引导目光，不用3D旋转。转场匹配同一对象的位置与颜色。
- 动作：绘制路径、堆叠计数和形状连续变换；500–900毫秒平滑进出，重要数值完成后停留至少1秒。数字必须由数据驱动，不能出现插值造成的错误年代。
- 缺陷禁区：图标堆砌、无单位数值、不同人物体系混用、频繁弹性缓动、误导面积比例、装饰箭头冒充事实、不可读的小字号。

## 项目角色边界
16:9；蓝西装玩具向导必须使用同一份原始完整角色素材，小角标约为画面高度20%，不是画面宽度25%。保留头、颈、身体完整连接；没有经过验证的真正绑定前，不拆头、贴嘴、拼异质面部或假装口型同步。人物旁白音色尚待明确选择，不擅自视为已验收。

## 交付前检查
- 逐镜核对风格、历史依据、主事件动作及可读停顿，区分事实和示意。
- 检查完整角色、向导尺寸、字幕避让、素材版本、镜头连续性与声音状态。
- 运行共享 JSON 验证；它只能检查结构，不代替逐帧视觉检查。
- 有实际渲染时查看首帧、中间帧、末帧及运动中的遮挡/穿模；汇报渲染器、命令、版本、输出规格和未解决缺陷。
