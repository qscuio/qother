# 数据编码与标注

量化画面先确定可核查数据，再选图形；不用戏剧性变形替代事实。这是可复用方法，不是引入另一套 dataviz 美术风格。

- 为数据列记录名称、单位、范围、来源/许可、基准期、缺失值与估计属性，按列名取值；将旁白每个数字映射到实际数据。不补造缺测值或未来数据。图表说明区分测量、模型估计和纯示意。
- 比较类别选条形，连续变化选折线/点列，分布选直方/点群，两指标关系选散点，前后对比选坡度图；地图只在地理位置承担解释时用。关系不等于因果，Sankey 的流量须有守恒/口径依据。
- 长度、面积、颜色各自只编码明确变量；面积图按面积换算，不用半径直接代表数量。条形比较通常从零开始；若裁轴、对数轴或分段尺度，显式标记且说明理由。前后镜头不要静默变尺。
- 有意义的正负基准才用发散色带；无中心顺序量用连续色带。基准期和数值范围锁定，不能为戏剧感拉伸色阶。同一概念跨镜保留语义，颜色不是唯一识别线索。
- 标注锚在数据值/对象 ID 上，加独立屏幕偏移；变尺/移动时重算。轴滚出屏幕后仍保留必要单位/刻度参照。标注与后续数据、字幕及主持人冲突时重排，不能缩小到不可读。
- 图表变形先定义同一条数据的身份映射，明确旧/新编码及单位。过渡中若长度/面积不再可定量读取，应短暂弱化读数并标为布局过渡，不能出现看似真实的插值年代或数值。变形不是新数据。
- Isotype 重复图标需说明一个图标代表多少、余数和舍入；总数核对，不能既改变图标大小又改变数量导致双重夸张。保留未知项，而非把空白当零。
- 音高映射数据只作可选辅助：说明映射尺度/截断，静音仍应读懂；不强制每个数据点对应音符或音乐节拍。

复核例：标注在 rescale 后仍指同一记录；不等宽时间间隔没有画成等速；两组数使用同一单位和基准；缩略播放下单位和关键限定仍可读。结构与计算核对通过后仍需实际静帧/动态检查。
