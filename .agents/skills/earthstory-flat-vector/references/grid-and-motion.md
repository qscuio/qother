# 网格、文字与关系运动

保持现有色板与纯色矢量。借瑞士排版的网格和无弹跳运动、数据叙事的语义变换，不新增另一套“瑞士风格”skill。

- 1080p采用24 px基线与12列候选网格，边界由本镜头内容和角标避让确定；网格是对齐工具，不是固定左右面板。标题48–60 px、正文/标签30–36 px、字幕40–48 px起步，同一已授权中文无衬线家族最多三档字重；手机缩览不清就减少信息，不能不断缩字。
- 暖白底/墨字维持不变；青绿用于本镜头主关系，赭黄用于对比，必须在图例写明含义。单一重点镜头只留一种强调色；多系列真实数据可按数据参考采用必要编码，不能为了“只能一个色”破坏图例。
- 一镜以一个有意义的网格模块承载一个年代、区域或数据单位；对齐数据时共用基线和尺度。巨大数字必须同时带单位/对象，面积不能代替长度编码而不改标尺。
- 默认固定构图；必要时按主skill做受控局部放大，明确投影不变以及数据尺度是否改变。一个关系展开完再进入下一个。动作优先遮罩揭示、路径增长、同对象重排；图形平移候选500–900 ms无过冲，线条生长匀速。重要结构完成后留实际读图时间，不以音乐节拍压缩旁白。
- 转场通过同一个数据点、同一地理对象或同一时间锚点连接；数据变化和镜头缩放须分别说明。不用随机数字扰动、90度旋转中文字、蹦跳柱图或无依据的曲线插值。
- 例：地质时期比较先显示共同时间轴和断轴说明，再展开各时期；不把不同跨度画成等宽却不给出“非比例时间轴”。
