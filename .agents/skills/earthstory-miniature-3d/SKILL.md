# 微缩模型三维历史场景

## 使用范围与状态
候选实验方向，未获用户选定；没有确认可用的三维制作工具、模型或绑定。不能承诺已能渲染。
本文件是可调用的仓库级制作规范，不是已安装的渲染器、视频模型或运行中的 agent。

## 先读与输出
从本 skill 目录向上三级到仓库根目录。制作时读取 [共享流程](../../../docs/style-system.md) 和 [分镜契约](../../../docs/storyboard-template.md)。检查用户本次选择、事实来源、原始角色素材和实际工具；缺少素材或渲染能力时明确交付的是方案，不冒称成片。
输出本风格的镜头说明、符合共享契约的 storyboard JSON、版本锁定素材清单，以及真实执行过的测试结果。若用户只要求比较，不自动改动已选方向。

## 风格与运动规范
- 色板：沙土 #C6AD83、陶土 #A46849、苔绿 #65745B、炭灰 #404440；蓝西装仅保留在原始向导角标。避免糖果色和镜面金属抢主体。
- 材质：统一哑光陶土/手工微缩模型观感，物理粗糙度高、反光柔和；地貌与人物纹理比例一致。不要把扫描模型、照片贴图与玩具模型随意拼接。
- 形状/人物：圆缓简化体积、稳定底座；历史人物全身采用同一比例与可复用骨架。未验证绑定前只用静态完整模型或物体级运动，不制造肢体动画。原向导保持完整二维叠加，除非用户另行批准重建。
- 场景：一镜一个可辨认微缩空间，前中后景关系清楚；地貌演变由可追踪形体变化表达。建筑、服饰和工具的时代地域一致，示意夸张须标注。
- 灯光：一个大面积暖主光、较弱中性补光；软阴影，接触点有接触阴影。曝光与白平衡跨镜锁定；不用黑洞式阴影或过曝白边。
- 摄影：35–55毫米等效镜头或正交镜头任选其一并锁定；相机平滑短距离移动，单镜不用绕场大旋转。景深弱或关闭，确保关键结构与字幕清楚。
- 动作：物体要有重量、支撑和碰撞逻辑；人物脚底固定接地，搬运先接触再移动。推荐平滑加减速，禁止无动机漂浮与穿模。只在工具实测支持时使用骨骼动画。
- 缺陷禁区：穿模、脚滑、悬浮、闪烁、材质随机变化、镜头穿墙、尺度错乱、假口型、断颈、塑料亮面和过强景深。

## 项目角色边界
16:9；蓝西装玩具向导使用同一份原始完整角色素材。位置/尺寸与现成男声普通话遵循[当前制作配置](../../../docs/production-style.md)；主持人参考布局不等于整幅构图已获批准。保留头、颈、身体完整连接；没有经过验证的真正绑定前，不拆头、贴嘴、拼异质面部或假装口型同步。实际声音与画面质量单独验收。

## 交付前检查
- 逐镜核对风格、历史依据、主事件动作及可读停顿，区分事实和示意。
- 检查完整角色、向导尺寸、字幕避让、素材版本、镜头连续性与声音状态。
- 运行共享 JSON 验证；它只能检查结构，不代替逐帧视觉检查。
- 有实际渲染时查看首帧、中间帧、末帧及运动中的遮挡/穿模；汇报渲染器、命令、版本、输出规格和未解决缺陷。

## 具体视觉语法
设计或审查实际构图时读取[材质、排版与运动细则](references/material-and-spatial-readability.md)；保留本skill的状态和当前制作配置，参数须经实际画面验收。

## 共同导演方法与本风格检查

分镜或大改前读[导演与质量契约](../../../docs/video-production/direction-quality.md)，在现有统一流程、分镜、实测音轨及 QA 台账内执行。候选状态和工具待验证边界不变，不因此重启冻结任务、替换已批准声音/规格或声称已有三维能力；单独安装时定位同一共享参考。

- 构图/语义：先用轮廓、接触点和前中后景建立空间证据，再加材质；相机揭示与物体实际变化分开说明。微缩夸张、剖切和时间压缩标明范围，不能靠景深/暗部隐藏关键结构。
- 运动：有明确起点、揭示和终点才移动相机；固定机位可优于绕场。搬运先接触再运动，支撑、重量、碰撞和脚底接地可追踪；未验证绑定不编造肢体能力。涉及模拟时锁种子/缓存及时间基准，任意帧求值不得依赖上一次播放状态。
- 时序：沿实测音轨给空间定位、动作结果与标签留读取时间；接触/释放等已帧对齐事件检查目标帧，估计语词时刻不宣称帧级精确。镜头停止可用于阅读，不用无目的漂移填空。
- 验收：短链路选含前后遮挡、接触与标注的实际三维镜头；查接触帧、遮挡交换、相机路径和首中末，再连续播放检查穿模、脚滑、闪烁与曝光。回取同帧验证状态稳定；有实际音轨才审声画，记录工具/资产版本和未做项，不用漂亮静帧代替动态通过。
