# 地球往事：句段精修

让已有的意思说得准确、具体、有节奏；好段落可以原样保留。用户只要审阅就给诊断，不擅自改文件。

## 先确定改动层级

读目标段、上下文与事实记录。定位一句或一段的实际困难，说明它怎样影响理解。中心认识不清、材料失焦、机制缺失、信息顺序错误，应转 `$earthstory-scriptwriting` 做结构修改；删套话不能补出不存在的内容。

读[中文改写示例](../../../docs/writing/deslop-examples.md)校准修改幅度；需要判断详略、转场、比喻或节奏时，只读[写作手册](../../../docs/writing/narrative-craft.md)相应小节。

## 选择能解决问题的改法

- 抽象判断遮住动作：用材料已支持的对象、动作和后果承载意思。缺证据先指出缺口，不即兴加细节。
- 句子难跟：让条件靠近判断，代词靠近所指，已知信息引向新信息；按关系分句，不把每句剪成同样短。
- 段落单调：调整详略、句势与落点，让重要变化有空间。重复若用于定位或照应可以保留；无新意的重复才删。
- 修辞抢走内容：检查比喻是否帮助看懂关系、是否引入错误机制。真有用途的形象表达保留，不把精修做成无色提纲。

“壮阔”“不是……而是……”或长句只是检查线索，不是禁词或句式罪证。不添加虚构亲历、情绪、粗口、对白和口头填充来制造人味。没有实际问题就说明保留理由，不用同义词替换制造工作量。

## 保义并复核

保护对象、动作、时间、数字、范围、否定、因果方向、归属与确定程度。“约”“可能”“之一”“模型显示”可能承担事实功能，不为有力而删。保留原意不代表原意已正确；事实疑点单列核验。

没有事实记录，只作意义不变的语言修改。重要改动简记“原处／困难 → 修订 → 理由 → 事实复核”，小改可合并说明。回读前后段，检查是否抢答后文、重复前文或改变声音；意义等价无法确认就缩小修改或标记待核。

交付干净修订与少量有代表性的修改证据。按[共同验收](../../../docs/writing/editorial-rubric.md)选择本段适用项；缺少全片、声画或系列材料就标未检查，不假装全片通过。不得以去 AI 分数、禁词零命中或校验器通过代替实际文字判断。既有技能研究出处见[deslop 调查](../../../docs/writing/deslop-skills-survey.md)。
