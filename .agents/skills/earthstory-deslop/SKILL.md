# 地球往事：去套话与精修

让已有的意思说得更准确、具体、自然。先有值得讲的内容，再做这一轮；不要用替换词表假装完成创作，也不要把好好的句子强行改出痕迹。

## 确定边界

用户只要审阅时，给诊断与建议，不擅自改文件；要求改稿时再交付修订。保留原意不等于原意已经正确，发现事实疑点应单独标明并核验。

读目标段落、上下文和相关事实记录。没有事实记录时，只作意义不变的语言修改；遇到需要新细节的地方提出具体信息缺口，不自行补造。

保留人物／对象、动作、数字、时间、范围、否定、因果方向、来源归属及确定程度。“约”“可能”“之一”“目前证据”“模型显示”等词可能承担事实功能。先理解它们为什么在这里，再决定是否冗余。科学判断不能为追求有力而升级成确定结论。

若困难来自中心认识不明、解释缺失或段落逻辑断裂，指出结构问题，转用 `$earthstory-scriptwriting`。本技能可以修复局部表达，不能用一组漂亮句子遮住内容空洞。

## 找真正影响读者的地方

把以下现象当线索，不当禁令：

- 先宣布“意义重大”，后面没有具体说明；用“共同塑造、深刻影响”代替发生的事。
- 每段都总结同一个意思；结尾重新宣布故事才刚开始，实际没有新问题。
- 假设没人提出的反对观点，再反复用“不是……而是……”反驳；必要的真实对比应保留。
- 抽象名词和多层修饰堆叠，谁做了什么被隐藏；转场词掩盖两句并无关系。
- 同样长的句子、同样的排比、每段同样的收束方式，让内容听起来像模板。
- “壮阔、神秘、震撼”等形容词可套在任何题材上；比喻没有解释作用，或偷偷改变机制。

先说明问题在具体哪句、对理解有什么影响。没有实际问题就保留；普通连接词、否定句和必要重复并不天然差。

## 有针对性地改

用原材料中已获支持的对象、动作和结果替代空泛判断。该补解释时补解释，该删重复时删重复；不能只删到剩提纲。允许长短句随内容变化，不强制字数、感官词、修辞、段落或钩子配额。保持克制而有表现力的中文，不加虚构亲历、情绪、对白、粗口或口头填充词来制造“人味”。

每个重要修改保留一个简短的“原句／问题 → 改句 → 理由 → 事实复核”记录。记录放编辑说明，不混进干净旁白。小改可合并说明；无须为每个标点建立审计表。

完成后通读相邻段落，检查新句是否重复前文、抢答后文或改变语气。逐项复核有变化的时间、数量、条件、否定、归属与确定程度；需要时回查原来源。事实等价无法确认，就缩小修改或标记待核，不宣称已通过。

需要校准修改力度时，读 [保事实的精修示例](../../../docs/writing/deslop-examples.md)，分别检查应改、应保留、应先补研究的情形。

## 交付

给出干净修订文本和少量有代表性的修改证据，说明仍需结构重写或事实核验之处。用 [共同验收标准](../../../docs/writing/editorial-rubric.md) 检查适用于本段的内容与表达维度；缺少的全片或声画上下文标作不适用，不计分。必要时作明确标注的模拟初读或文本口读检查。

这是一套编辑方法，不检测或保证文本的人类／AI来源，也不保证读者偏好。不得用“去AI得分”、禁词零命中或校验器通过代替对实际文字的判断。公开研究出处、六个实读技能的固定提交链接与采用／舍弃的理由见 [deslop 调查](../../../docs/writing/deslop-skills-survey.md)。更广的故事方法见 [研究索引](../../../docs/writing/research-index.md)。
