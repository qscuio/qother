# 人物动作素材

先读[当前制作配置](../../../docs/production-style.md)；涉及镜头合成时再读[分镜契约](../../../docs/storyboard-template.md)。这是跨风格的素材工作流，不是新风格、已安装工具或已完成角色动画的声明。科学宇宙场景的真实三维要求保持不变。

## 从参考到可复用资产
1. 锁定用户认可的单一身份参考及其版本、哈希、权利依据。沿用已批准参考的取景（当前半身主持人的头、颈、肩与上半身连续完整），明确朝向、服装与左右配饰；不强制补出腿脚或缩成全身小人。不得用另一张“看起来相似”的新图替换。已有同版参考批准证据即可沿用，无需重复批准；缺少获批参考时先停在参考审阅，不生成动作库。
2. 按[动作与加工流程](references/workflow.md)选小型动作目录，一次定义一个动作的起点、变化、终点、时长与循环语义。每个动作独立出候选，继承同版身份参考；失败只重做受影响的候选，不重画已批准资产。
3. 把生成源和原始单帧留为不可变记录；加工另存版本。统一画布、支点和尺度，保留真实动作位移，检查实际 alpha 与衣服/发丝边缘。250 px 圆角标只是最终合成裁切，不是生成画布。
4. 展示全部候选帧、选中顺序、原参考和实际速度预览，允许人工拒绝、替换与重排。明确记录选择，不能把删除坏帧、变速或手工修整说成自动通过；改后重做时序检查。
5. 按[资产契约与验收](references/asset-contract.md)分别记录静态逐帧、视频时间采样、连续动态审查与用户批准。只复用获批的具体 state + asset_id + version；导出应用挑帧结果的独立透明 PNG，atlas 仅为可选派生物。

## 权限与失败出口
- 本次集成只提供方法文档。执行工具、上传原角色、付费模型、外部凭据、视频生成或发布均不由本 skill 授权。只用任务中已获授权且实际可用的工具；不安装或运行 sprite-gen，不读取/清理本地会话记录。未来采用工具须独立检查其范围与权限。
- 身份漂移、解剖破裂或无连贯动作：退回该动作候选，不靠贴嘴、补脖子、放慢播放掩盖。无法形成合格序列时如实交静态候选/缺陷报告，不声称动态通过。
- 本流程不提供音素/视素对齐。需要随旁白说话时，另立明确的口型与叙述同步管线并验收，不能随机循环张嘴充当口型。
- 当前静态/完整图层限制只在尚无获批动作或可用绑定时适用。用户可明确修改冻结内容、状态或范围；修改生成新版本并重审受影响项，不把当前限制写成永久禁令。
- 动作资产获批不等于镜头获批。视频前仍须用户明确批准同版分镜和构图关键帧；未获批停在审阅包。

方法由 sprite-gen 的参考锁定、分动作流水线和非破坏式 curation 改编，参见[取舍、来源与许可](../../../docs/sprite-gen-adaptation.md)。
