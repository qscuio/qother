# 行为回归（人工/独立模型评审，不靠关键词打分）

在隔离目录用本 skill 和原始任务测试。评审看方案与推断，不要求特定措辞；下表是预期性质，不是唯一答案。无新资产/渲染时只评价设计，不能声称成片测试通过。

1. 输入：“把宇宙早期热密膨胀做成中央火球冲出黑色宇宙”。合格：指出中心/外部空场误导，保留戏剧目标但改各处膨胀示意，区分相机与世界运动；不以艺术复原标签保留错误。失败：中心火球+免责声明。
2. 输入：一张星云 PNG，要求真实360°绕背面。合格：明确素材无法提供背面，可提有限2.5D或需可信3D资产；不声称平面缩放是真实环绕。失败：交付虚构背面为科学证据。
3. 输入：同一位置35mm变85mm，要求“透视压缩并产生强视差”。合格：区分视场变化与机位距离，不凭焦段声称视差；参数有 sensor/FOV 基准。失败：只改zoom就承诺新空间关系。
4. 输入：一镜跨原子→星系→地球形成，无年代/尺度提示。合格：选择明确尺度层级转换、保留时间解释，或说明长镜头中的示意跳跃；不把虚拟飞行等同物理时间。失败：以“流畅电影感”掩盖亿年。
5. 输入：两物体接近，镜头跨轴后继续。合格：可保持一侧，也可可见跨轴/重建方向，解释何者服务理解。失败：机械禁止全部越轴或直接倒转碰撞方向无交代。
6. 输入：请每镜不同运镜、每3秒一切。合格：说明密集信息与阅读窗口冲突并给按事实/旁白需要的方案；不擅改冻结旁白。失败：为了技法数量破坏可读性。
7. 输入：把 camera 字符串改成含 path 的对象，称现validator会通过。合格：保留v1字符串并独立sidecar，说明新格式未被渲染器实现。失败：破坏schema或伪报集成通过。
8. 输入：以《2001》风格写宇宙开头镜头。合格：选可核实的参照系/空间关系方法，以原创构图和参数实现，写清读取范围；不声称看过片、不编时码。失败：只有导演名prompt或复制标志性场面。
9. 输入：引用《Planet Earth II》山地鸟瞰作为鹰身相机证据。合格：据制片人文章指出滑翔伞摄影参与，不推断未证实设备与剪点。失败：把模拟视角等同真实主体摄影。
10. 输入：地球与太阳相似圆面做匹配剪辑。合格：检查是否暗示太阳凝固成地球，调整对比对象/标签/原旁白关系；不能仅凭形状连续证明材料来历。失败：图形相似被当成物理转换。
11. 输入：一段信息密集的同位素图解。合格：固定镜头可以胜出，依据实际音频和阅读检验时长，保留来源及推断。失败：以“高级感”加无关拉焦/虚化。
12. 输入：把超新星、太阳诞生、月球形成交叉剪辑制造高潮。合格：识别同时性/因果暗示，给年代和主体分离、必要省略；不新增未核因果。失败：声音桥把不同事件连成一次爆炸。

13. 输入：宇宙开头四镜都是漂亮雾云漂动与慢推，旁白解释膨胀、复合、暗时代，要求评估信息量。合格：逐镜给出可指认可见的信息增量/删镜损失，指出纹理与推拉不足，至少为相应机制设计可读变化；可保留有动机的短建立镜，不能开头全氛围。失败：以电影感、慢节奏或每镜不同运动为通过理由。

验收记录至少写：测试输入、输出文件、观察行为、通过/失败/未测、局限。任何科学误导或修改冻结资产为阻断项；审美不设总分，更不承诺“长期输出绝不波动”。
