# 连续性、剪辑与信息节奏

搜索词：180度、30度、视线、动作、图形匹配、建立镜头、insert、J/L cut、交叉剪辑、平行剪辑、蒙太奇、转场。

## 空间先建立，例外要有出口

180度规则是保持银幕方向的连续性惯例：先定义主体之间或行动方向的轴线，通常把相邻观察点保持在同一侧。它不是要求相机永远不能移动180度，也不是对任意两镜的角度计算。跨轴可通过观众看得见的连续移动、明确正轴/中性视点并重新建立方位、或新的全景重建关系；故意迷向可用，但要说明为什么，不能损害科学因果。新场景可重建新轴；不硬把上一场的轴延伸到宇宙。

30度规则是避免同一主体相邻机位差异过小而显得跳动的经验；配合明显景别变化、动作切点和信息目的判断，不是29度失败31度成功。允许有意 jump cut 表示省略，但不能意外丢掉过程关键步骤。数字图解也需要视觉区分，不必虚构机位角度。

视线匹配：先给观察者朝向，再给合理方向的对象，返回反应时方向一致；无人宇宙不要凭空制造“见证者视线”。动作匹配：切前起动、切后接续同一阶段，检查位置、速度、方向、接触顺序，不能重复撞击或漏掉接触。图形匹配：形状/位置/方向接近帮助注意转移；它只建立视觉关系，不证明两物同一、相邻或有因果。

建立镜头不一定首镜，也不一定大远景：地图、稳定地标、关系全景都可。先局部引起问题再揭示整体也成立，但不能让迷惑跨过需要理解机制的段落。插入特写要有来源/归属，返回后环境和动作状态可衔接。

## 转场按关系选

- 硬切：新信息、视点或阶段已经准备好；是正常首选，不必用叠化掩盖缺乏关系。
- 动作切：同一事件继续，切点落在可追踪阶段，绝非“任何运动都能接”。
- 图形匹配切：建立对照/概念承接；年代、尺度变了就同步标明。不要让恒星圆面直接变成地球暗示同一恒星凝固。
- J cut：后一场声音先于后一场画面进入，制造预期/导向；L cut：前一场声音在后一场画面继续，保留思绪/因果余韵。精确记录音轨边界；全片连续旁白跨切不必都命名为 J/L。科学限定不能因提前/延后而指向错误对象。
- 交叉剪辑：交替行动线常使观众推断同时发生，使用前确认同时性证据或明确“不同时”的时间锚点。
- 平行剪辑：可作主题比较，不要求同时；不同地域/年代、示例与特定事件必须区分。两词的行业用法有重叠，以实际时间语义为准。
- 蒙太奇：压缩过程/聚合证据。保留关键机制与时间范围，不以快切把相关性变因果；不同恒星的生命历程不能蒙成同一颗恒星完成所有路径。
- 叠化/淡出：可用于流逝、关系柔化或章节结束，但叠化本身不给出“过了多久”。两个阶段重叠的半透明图像不能造成混合结构误读。
- 遮挡转场/whip/亮闪：只有遮挡、方向或事件足以驱动且不会覆盖证据时采用；宇宙闪白不能代替未知机制。

## 信息和情绪的速度

逐镜记录：观众先识别什么 → 何时出现新变化 → 何时能看懂结果。复杂图解需要看懂因果的停留，不以固定镜长或BPM决定；单句可多镜，数句也可共镜。用反应/结果/静止留出理解空间，不强迫每个旁白重音对应一次镜头动作。

同类镜头连续使用不自动失败：比较实验可需同机位。只有在信息功能相同而无增量时，才调整景别、停留或删镜；不能为了“节奏变化”随机打乱科学次序。音画合看后复述“发生了什么、先后怎样、凭什么”，比镜头数量指标更可靠。
