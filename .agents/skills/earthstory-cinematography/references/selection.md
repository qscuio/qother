# 选择：意义 → 视点 → 镜头

以下是项目设计启发式，不是行业强制参数。搜索词：景别、焦段、透视、负空间、高度、轴线、决策树。

## 决策树

- 观众缺什么？
  - 不知道“在哪里/彼此何处”：建立镜头、空间锚点/地图；不要直接堆特写。
  - 知道场所但没看到关键变化：保持机位让动作完成；必要时插入证据特写。
  - 需要发现被遮挡的关系：有动机的摇摄/横移/升降揭示；若路径本身无意义，直接切更清楚。
  - 需要从环境进入局部：先决定这是同一空间的接近，还是尺度层级切换。前者推进，后者有标识的切换/图解。
  - 需要比较两个状态：同机位/同尺度对照，或清楚标注的并置；不靠不同焦段制造大小差。
  - 需要时间流逝：有年代锚点的省略、叠化或蒙太奇；不能拿无缝长镜头掩盖亿年跳跃。
  - 需要余韵：停止新增信息、让结果停留；未必需要拉远。
- 摄影是否必须动？明确可见的新信息/观看位置/情绪变化；说不出就固定。
- 是否有足够几何和素材支持？只有单张图就写平面裁切/2.5D，不伪称真实环绕或真实空间穿行。
- 它会制造错误推断吗？“镜头前进=物体加速”“图形相似=同一物体”“并剪=同时发生”任一风险未消除就改镜头。

## 景别不是大小形容词

- 大远景/远景（ELS/WS）：主体与环境的关系、分布和方向。留可识别锚点；远古宇宙无可用人类尺度时不可随意加宇航员作参照。
- 全景/中景（FS/MS）：完整动作及相互作用。非人物镜头按主体占画幅和可读信息定义，记录 bbox 或覆盖范围，不硬套“腰部以上”。
- 近景/特写（CU/ECU）：细节、证据和转折。切前/切后建立其归属；细节被放大不代表其物理尺寸变大。
- 插入特写（insert）：信息功能而非单独景别。它应回答“发生了什么/凭什么知道”，并有返回主场景或进入下一层的出口。

## 焦段与透视

先写目的（环境关系/主体分离/平面比较），再写实际镜头参数。透视取决于观察位置及物体距离关系；在同一位置换焦段主要改变视场与放大，不会单独创造新的透视。常见“长焦压缩”含有为保持构图而后退的机位变化，不能把两者混为一谈。

需要物理参数时给 sensor/filmback 或明确等效基准、焦距、机位距离与视场。没有传感器设置的“35mm”只是模糊提示。2D 正交图解用 viewport 和 scale；不要假装有摄影镜头。广角近位利于展示前后关系但易夸张近大远小；远位窄视角利于挑出局部但易隐藏间距。科学尺寸对比优先统一投影、距离与图例。

浅景深把注意力移向一个平面，不是“高级感”开关。原子/天体示意的失焦可是假定视觉语法，不能冒充真实望远镜/显微镜观测效果。

## 构图、负空间、机位

中心/对称适合稳定比较、系统结构；三分法适合方向和环境关系，均非硬规则。让最重要变化有视觉优先级：亮度、色彩、清晰度、位置、运动不要同时抢焦点。负空间用于让方向、孤立或未来揭示可感知，不能用大空白挤压字幕和关键证据。

平视有利于中性比较；低位可显体量、高位/俯视可读关系，不能自动等同“强大/弱小”。倾斜机位是失衡信号，图表、地层与轨道不能为戏剧感倾斜到难读。顶视适合盘和地图，斜视适合厚度，转换时保留地标/轴向。宇宙没有全球“上方”，定义的是镜头局部 up 向量，不是科学方向。

保留项目向导和字幕安全区；科学标签按观众实际屏幕尺寸试读。构图要包含运动过程中最大的占位，不只验证首帧。
