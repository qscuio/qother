# 可复用动作库

检索 ID 进入相关项即可。参数是设计变量，不能直接把示例秒数/角度复制到每镜。每项都要填契约里的 why、路径、时长、ease、视差和停止点。术语基础见 sources 的 CINE-02；数字对应与风险是本项目综合设计。

## M00 固定 / locked-off
目的：让主体变化本身成为证据；比较前后。适用：碰撞结果、成分变化、日期/图解阅读。禁忌：主体移出画幅或关键关系一直不可见，却以“克制”掩盖。数字对应：相机/viewport 不动，物体可运动；参数记录无相机位移。QA：不能把整图缩放误报固定。

## M01 摇摄 / pan、tilt
目的：转向注意对象、跟住方向或揭示画外关系。机位固定，旋转 yaw/pitch；记起止角、转动枢轴、目标及首末停留。适用：从地层底部看到顶部、沿已建立方向寻找主体。禁忌：用摇摄冒充横移，或无空间锚点快速扫过不可读证据。数字对应：3D 相机旋转；平面素材的 viewport 平移只能称平面摇移模拟。QA：边缘拉伸、运动模糊、标签漂移；whip pan 仅在快速方向转换有理由且不牺牲证据时用。

## M02 推进/拉远 / dolly in-out
目的：接近细节/显出环境，观看位置真的变化。路径沿或斜向视轴，写目标距离变化、look-at 与终点构图。适用：从云团环境接近一个模型区域。禁忌：从银河连续飞入原子而不交代尺度、时间与示意。数字对应：3D translation；单图 scale 是裁切放大，不具有真实推进视差。QA：近远关系变化、碰撞穿模、目标尺寸与旁白是否误读。

## M03 横移/轨道平移 / truck、track
目的：显露遮挡后的关系，沿行动维持观察。路径横向或自定义轨道，明确与主体是同速跟随还是相对穿过。适用：穿过有实际深度的尘埃层、沿河岸/队列建立空间。禁忌：为了“动”让科学标签飘走或重排物体。数字对应：3D translation；2.5D 分层按深度安排相对位移。QA：前景快、远景慢来自设定深度；不能让相机运动被理解成云团互相奔离。

## M04 升降 / pedestal、crane、jib
目的：从局部动作升到系统关系。机位高度变，不等于 tilt；crane 可有弧形路径，记位置与朝向各自曲线。适用：从盘边缘升到能辨认环带的视角。禁忌：上升后凭空增加科学结构、混淆盘面与剖面。数字对应：虚拟相机升降或路径；一张图向下滑不声称真实俯视揭示。QA：中途主体遮挡、透视连续及 up 向量。

## M05 跟随 / follow、leading、stabilized、handheld
目的：保持一个行动主体与环境关系。可在后方、前方引领或侧面同行；跟随是关系不是设备名。适用：历史场景行动、尺度一致的物质迁移示意。禁忌：把某颗示意粒子一路追到地球当成已知材料履历；虚构早期宇宙现场手持记录。数字对应：目标约束加平滑路径；手持扰动只在选定叙事视点需要时可控加入。QA：遮挡、方向、追随延迟、晕动，不能把抖动当真实性证据。

## M06 环绕 / arc、orbit
目的：解释厚度、表面、结构关系，或改变主体与背景对齐。给中心、半径、角度、up、look-at，停止于更有信息的视角。适用：有可信3D几何的行星模型、器物。禁忌：对平面图伪造背面证据；无动机全周环绕；将摄影环绕当作天体公转。数字对应：真实3D轨道；2.5D只做有限视差，不生成未验证侧背面。QA：轴线变化、背面是否有依据、纹理是否滑动。

## M07 变焦 / optical zoom、digital crop
目的：改变画幅选取而不换观察位置。给 FOV/焦段或 crop 起止、固定机位和中心锚点。适用：从总图挑出局部、强调观察行为。禁忌：宣称变焦会自动产生新视差；裁切过度低分辨率。数字对应：3D FOV 改变或平面缩放；区分两种。QA：主体放大与科学尺度标签同步，安全区/分辨率。

## M08 焦点迁移 / rack focus
目的：同一构图中依次让两个平面成为信息。给 A/B 目标、焦点距离或2D模糊半径、开始/完成时刻和读懂后的停留。适用：已建立前后关系的物件、证据和背景。禁忌：以虚化隐藏必要限定；把天文图像随意加浅景深冒充光学测量。数字对应：物理 DOF 或明确的图层显隐/锐度强调；后者不能称物理对焦。QA：焦点转换可读，无无意呼吸/标签失焦。

## M09 多层视差 / multiplane parallax
目的：有限深度提示与观看位移。视差是不同深度在视点变化下的相对位移，不是每层随机漂动。适用：纸感层景或写实2.5D雾云。禁忌：把纹理分层误当实际密度、星距或膨胀数据。数字对应：深度排序、运动方向、每层位移比例、遮挡修补；不暴露无素材区域。QA：近层位移较大是否符合视点，主体完整、无剪纸漏洞。

## M10 长镜头 / long take
目的：维持空间、连续时间或逐级揭示，让场内调度而不是切换完成注意转移。可完全固定；不是“最长轨道”的同义词。适用：一个可理解的连续过程。禁忌：把数亿年和多个尺度伪装成不间断见证、为避免剪辑牺牲解释。数字对应：分段 keyframes 仍须统一空间/时间约定；隐形接缝不得隐瞒实质跳时。QA：阶段可辨、结果停留、轨迹和速度无突变。

## M11 反向变焦 / dolly zoom（有条件）
目的：主体画幅近似不变而环境比例改变，制造知觉冲突。相机距离与焦距相反联动。适用：明确主观感受；通常不适合中性科学解释。禁忌：暗示天体空间真的扭曲，或把视觉不适当作科学结论。数字对应：同时调整3D距离/FOV，不能只拉伸背景。QA：畸变用途必须说明；不必为了库覆盖而选用。

## 共用 timing / ease

先用旁白和事件动作确定可读窗口，再分配 hold → movement/reveal → hold。持续匀速适合追随或比较；缓起缓止适合观察者有意停住。选择 linear、smoothstep 或具体 Bezier 并说明区间；不把全片每镜都做同样 S 曲线。实际物理运动用模型自己的速度规律，不能跟随相机 ease 随意加减速。电影感来自速度、构图和信息时机的配合，不来自某一曲线名。
