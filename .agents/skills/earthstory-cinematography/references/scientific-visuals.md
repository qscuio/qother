# 科学纪录片：镜头不能偷偷增加事实

## 每镜三条独立轨道

1. 世界状态：物质分布、主体运动、可支持的机制和年代。
2. 观察者：相机位置、朝向、视场、焦点、展示速度。
3. 解释层：图例、尺度、日期、箭头、比喻和声音。

拉远使画面内物体看起来更小，不等于物理收缩；推进产生的粒子掠过不等于粒子高速飞行；环绕不等于天体自转/公转；2.5D视差不等于已知三维距离。检查时可分别冻结世界/相机，查是哪一轨制造了运动。科学图解不能靠相机误差获得想要的结论。

## 宇宙开头硬边界

- 空间膨胀不是黑色外部空间中的中心火球爆炸。有限画面不代表宇宙边界；摄影视点不是宇宙中心。若以粒子/格点演示，只表达局部间距变化，并标注非比例示意，不能宣称真实微观粒子画面。
- 早期热密期与约38万年后的复合、暗时代、第一批恒星不是同一场景的几秒自然演化。跨阶段必须有旁白/年代/明确时间省略，不能加入尚未出现的恒星作为漂亮背景。
- 约38万年后光更能传播，不画成“第一颗星亮起”或一束中心发射的新光。颜色/亮度是展示选择，不自动是肉眼会看见的颜色；CMB假色图须说明观测图与艺术复原差别。
- 从大尺度宇宙切到原子图是解释层转换，明确“微观过程示意/非比例”。不连续缩放伪称同一物理相机可穿越所有尺度。
- 恒星内部剖面、超新星、银河、原行星盘的相似颜色不能暗示一个主体依次变成所有阶段。真实恒星多种路径与时间重叠需保留；太阳不应被剪成未来超新星。
- 粒子黏合、反弹、破碎和星子形成模型需有不同结果/限定；不要将尚在研究的路径画成唯一必经步骤。
- 地球形成约45.4亿年前是年龄估计，不是瞬间“出生证”；镜头中的成长/分异不应压成一天。月球形成属于模型复原；撞击角度、材料比例、聚集时长无可靠支持时不得以写实细节冒充定论。

以上从冻结脚本及其 source_id 限定接入；本 skill 不取代每集事实审稿。新增细节仍需新增/复核主张—来源映射。

## 尺度、时间、比喻

记录空间范围/单位/投影和时间范围/展示倍率。无比例的艺术复原明确写 `not_to_scale`；相对大小参与解释时必须核实。线性与对数尺度切换需可见提示。显示时间压缩不等于给出真实均匀速率；世界和相机的 ease 分开。

每次跳年代/位置/尺度记录过渡提示和可能的错误推断。图形匹配、声音桥和无缝接镜尤其容易掩盖跳跃。“同一类材料循环利用”不能被一条粒子追踪路径替换为特定原子的可考履历。

比喻在出现时就标“示意/尺度类比/艺术复原”，并让核心差别在解释上可知，不仅把免责声明藏在片尾。网格不是空间实体结构、橡皮膜不是宇宙外表面、声音设计不是真空中录到的环境声。可在制作/片尾说明非叙事内声音，不能标为现场声。

## 最小科学 QA

遮住旁白只看画面：会不会推断有中心、边界、目标意图、唯一机制、同步发生或可测比例？再听旁白不看图：画面是否恰好增加了脚本未承诺的细节？任何一个“会”都需要改图、转场或贴近相关画面的限定。单独加“艺术复原”不能保住明显错误画面。
