# 投影、材料层级与标签

- 固定等距投影与原有三档面色。1080p轮廓候选2–3 px、引线1.5–2 px；顶面最亮、受光侧中间、背光侧最暗，统一光向。放大不可另给每个模块随机阴影。
- 每种材料有稳定基础色：土赭=土层、灰绿=植被/生态对象、青绿=本镜头追踪流；真实材料变化与强调状态变化分别说明。三档明暗保持色相，不能换面就像换材料。
- 一套已授权中文无衬线，标题48–60 px、标签30–36 px作1080p起点；标签水平，编号和引线指向具体表面，禁止把中文强行压到斜面而无法读。
- 主剖面优先连续占画面；只在读图需要时加入一个局部窗。揭开外层时先标切线，再沿表面法线移开，最后出现切口边界；移开的是示意外壳而非真实物体裂开。
- 总览和局部共用同一投影；沿地层下移是相机平移，不能改变俯角制造“更立体”。数据单位图标如确有需要，数量由数据计算；不用弹跳、挤压改变物理尺度。
- 转场匹配同一层或流程节点；时间或地点改变必须显式标记，不能借钻进一个洞偷偷换地点。虚实和比例说明就近附着，不把小小“示意”当事实错误免责。
- 例：地壳剖面先显示地表定位，再打开示意切面并写出垂直夸大倍数；若没有倍数依据，明确非比例，不给假刻度。
