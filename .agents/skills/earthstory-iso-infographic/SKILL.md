# 等距信息图

状态：proposed-unvalidated。由本次方法集成提出，限候选方案/局部图解试验；尚未获用户选定或完成真实短镜头验收。它是独立风格 skill，不是部署的 agent 或已安装引擎。

## 输入与边界

读[共享流程](../../../docs/style-system.md)、[分镜契约](../../../docs/storyboard-template.md)、[当前制作配置](../../../docs/production-style.md)以及冻结旁白/来源与获准范围。若任务明确要求真三维透视、相机绕行或物理景深，不以本风格替代。

## 视觉规则

- 材质/投影：固定等距投影，平面色块与统一顶/左/右三档明暗；不做金属拟真或透视消失点。系统可放在可见剖面的底板上，底板须承担层次信息，不为装饰强加。
- 候选色板：暖白 #F5F1E8 底、墨色 #27313B 标注，赭土 #B78658、青绿 #397E82、灰绿 #708778、砖红 #AD5E50 按材料/角色赋义。每色的明暗派生须保持对比；不强制全片配色，不回到泛蓝科技面板。
- 形状/场景：体块轮廓能辨识，剖面边界、层理与真实对象对应；明确 NOT TO SCALE/示意的具体范围，标识不能豁免错误年代、结构或因果。需要数量时读[数据编码参考](../earthstory-flat-vector/references/data-storytelling.md)。
- 人物：必要群众可用完整简化图形，但头颈身体连接与接地一致；原始主持人单独保留为锁定屏幕层，不改造成等距小人、不导入公开资产包。
- 灯光：三档面色传达朝向，光向跨镜一致；这不是已校准物理光照。文字引线/切线用墨色；标签优先水平中文排版，不为上游英文全大写牺牲可读性。
- 摄影：固定投影下平移/受控缩放或切换系统板，追踪同一对象；不开绕行镜头。世界标注与对象共用投影，字幕和主持人留在屏幕层。纵向移动是平移观察层次，不暗中改变投影角度。
- 动作：先建立整体，再用切线/剖开揭示内部或沿有依据的流程追踪。固定镜头和静止物体可以成立；缓动只给布局/强调，物理过程不套弹跳、挤压。时长依实际旁白与读图停顿，无固定节拍配额。

## 审查与交付

危险点：复合体遮挡排序错误、移动实体半透明似幽灵、推近时标签脱锚、图标数量不等于总数、剖面误示真实比例。检查起/中/末帧与遮挡变化处，实际播放验证后才记录动态通过。

输出沿用共享 storyboard 与资产锁，并交关键帧、投影说明、事实/读图风险和 pass/fail/not-run。分镜与构图内部复核通过后按[统一流程](../../../docs/production-workflow.md)自主继续，无需逐项等待用户批准；实现能力另行验证。缺工具只交方案，不造渲染结果。行为案例见[集成验证](../../../docs/tests/lemo-opuscar-adaptation.md)。
