# 轻量空间运动：2.5D 分层投影

一个 1280×720、24 fps、6 秒的无声技术演示。固定种子生成 217,164 个带简单三维坐标的尘埃点；每帧用透视投影、双线性散点绘制和 12 层二维透明合成表达空间感。没有高精度网格、体积光线积分或路径追踪。

这不是物理模拟，也不是照片级视觉效果承诺。前 3 秒包含缓慢自身旋转、小角度相机绕行和观察倾角变化；后 3 秒保持视角并径向展开。展开是能力测试，不表示太阳形成时云团向外膨胀，不宜直接配收缩叙述。

## 依赖

- Python 3；实测 3.12.14
- NumPy（实测 2.3.5）、SciPy（实测 1.17.0）、Pillow（实测 12.3.0）
- 完整视频输出需要 PATH 中已有 FFmpeg，支持 libx264；单帧输出不需要 FFmpeg
- 已安装的中文字体。默认尝试 Noto Sans CJK、macOS PingFang 或 Windows 微软雅黑的常见系统位置；找不到时显式传入 --font

本包不自动安装依赖、不下载字体、不联网，也不包含或自动加载私人主持人图片。

## 使用

只渲染一个无主持人画面：

    python render_motion.py --output ./render-check-01 --frame 36

--preview 等同于只输出第 36 帧；--frame 可选 0 至 143。完整 144 帧输出：

    python render_motion.py --output ./render-full-01

可选传入自己拥有使用权的主持人图片与字体：

    python render_motion.py --output ./render-check-02 --frame 0 --host-image ./portrait.png --font ./ChineseFont.ttf

默认没有主持人。提供图片时以居中正方形裁切适配既定右下圆形；如需指定构图，请自行准备方形裁切图。输出目录必须是新目录或空目录，脚本拒绝覆盖已有内容；FFmpeg 也使用 -n 禁止覆盖。

## 检查与证据

- 当前便携版：语法检查通过；第 36 帧无主持人渲染与目视检查通过；非空输出目录保护通过。
- 指定相同输入图片时，第 0 帧曾与原技术演示逐像素相同。此测试后仅增加 FFmpeg 禁止覆盖与完整输出元数据，未改投影算法。
- 当前便携版完整 144 帧重跑：not-run。完整编码分支尚未用本便携 CLI 重新端到端执行。
- 原算法在云端 CPU 工作区的既有运行：144 帧绘制及编码 99.14 秒，全片解码通过，并检查六张解码采样。该记录不是用户桌面的性能，也不是当前便携版完整重跑数据；不能据此推导相对其他渲染器的同画质速度倍数。
- 全速目视播放：not-run。相邻帧差分只是辅助检查，不能替代播放检查或保证没有细微分层变化。

validation.json 分开记录便携版检查与原运行；independent-check.json 记录发布复核的单帧耗时、文件指纹和输出保护结果。测试图片与视频不随仓库发布。所有记录不含私人素材路径。

## 局限

深度被分成 12 层，透明遮挡有近似；径向明暗是艺术预设，非真实照明。仅测试小角度视角，没有验证穿入云层或大幅背面观察。运动固定且可复现，但跨不同依赖版本的逐像素一致性未验证。

本包是方法样例，没有附带任何私人主持人、原演示完整视频或已停止的平面图解草稿；它不会改变其他项目的视觉风格。

运行 `python test_sources.py` 可检查语法、源文件指纹、CLI帮助和非空输出保护，不会启动完整视频渲染。requirements.txt 固定实测依赖版本；不会自动安装它们。
