# 地球往事

开篇从宇宙的早期演化讲到银河系、太阳系与地月系统的形成，再沿着地质变迁、生命演化、人类出现与文明发展的时间线，理解我们所处的世界。

本仓库保存《地球往事》的创作思路、制作方向和系列大纲。当前处于策划阶段；120 集、12 卷是供讨论和调整的工作方案，尚未锁定为最终集数、播出顺序或发布计划。

## 当前方向

- 以真实历史和科学证据为基础，解释地球与生命如何一步步走到今天。
- 地质部分交代宙、代、纪的层级，以及各时期的年代、海陆格局、气候与生命。
- 用有吸引力但克制的叙事连接知识，不靠猎奇标题或失真的戏剧化表达。
- 面向抖音与 YouTube，优先制作横屏版本。
- 画面主体是动态历史场景，小型卡通讲解角色在角落辅助。

## 下一步

本轮重写的是拟作为系列第一集的宇宙起源总览，叙述顺序为大爆炸后的早期宇宙、银河系、太阳系、地球与月球。当前请先审阅新旁白和事实核查资料；本轮没有制作分镜、音频或视频，正式单集时长尚未经过试读验证。

原 `docs/episodes/001/` 中的《尘埃聚成一颗行星》及其 24 镜骨架、三套分镜完整保留，作为地球形成旧稿的比较基线，不是新开篇的配套分镜。现有 120 集大纲和结构化分集数据仍是原工作方案，尚未根据新开篇调整或重新编号。后续编排需另行审阅，当前没有完整成片或已确定的发布排期。
