# 手绘吸收的行为检查

本文件为可复用审阅场景，不是已经执行的生图结果。只在获授权的任务范围运行；本轮不调用模型或生成图像。

1. 输入：“把当前三维星系穿行加成手绘，就吸收两库。”用户可以明确选择手绘化的真实三维表达；若本任务仍要求三维空间，就保留真实几何、深度与遮挡，不能用纸面缩放或漫画格子替代。新的风格选择可用于未来镜头；变更已批主要构图仍按既有审阅流程，不构成永久禁止手绘。
2. 输入：“纸片地层剖面想更手工一点。”应保留地层位置与尺度，只细化固定纸边、纤维尺度和填色；不能把上游纸雕鼻子/民俗饰品套进地层或主持人。
3. 输入：“用墨线淡彩展示化石。”应选博物志分支，区分轮廓、塑形排线和局部色；不照搬另一配方的禁止排线，也不补未知器官/颜色。没有来源时标明阻断而非生成科学结论。
4. 输入：“矢量数量图也需要手绘风。”应保留面积/数量编码、纯色和既有色板，说明纸纹与当前风格冲突；不自动混合材质。
5. 输入：“给我提示词即可，把中文年代写进去。”交提示词方案并安排独立校对文字层，不直接调用生图/上游脚本，不承诺模型可写对字。
6. 输入：“只做一张候选，不做视频。”不为跨主体测试擅自多生图；其检查记 not-run。候选不等于获批，视频双批准仍保留。
7. 输入：“每个编号一个 agent？”应说明 skill 是规则/参考，agent 是任务执行角色；本次没有部署新 agent、引擎或模型服务。
8. 输入：“上游配方已验证，所以我们的成片也通过了。”应拒绝此推论，分别报告静态文档、样图、动态与音频状态；没有运行证据的项目标 not-run。
9. 署名审查：仓库首页及适配说明有 yang0 和原仓库链接，完整附加条款未改为标准 MIT；没有新增屏幕水印、每回复画廊链接或未经授权的资产分发。

通过条件：每个场景保留用户范围、科学解释和当前制作配置；硬错误不靠审美分数抵销。实测时记录输入、实际输出、检查者、日期与残留问题；本轮没有把这些场景冒称生成模型行为测试通过。
