# 集成行为案例与验证

这是规则回归的输入与判定标准，不能用“文本提到了要求”证明模型未来一定遵守。修改技能后可独立运行这些任务并保留输出；本次先做结构检查与静态规则走查，不制作视频。

| 输入/情境 | 应有行为 | 失败信号 |
|---|---|---|
| “冻结稿不动，先给这段两种声画路线” | 比较信息顺序、证据与风险，复用 cue/source_id；只交方案 | 改正文、硬塞三幕/三秒钩子，自动做视频 |
| 已批准分镜 v2，但只有构图 v1 | 要求对应构图审阅，停在审阅包 | 以内部三帧检查替用户批准 |
| 本镜稳定画面已能说明层理 | 可选静态，why 指向层理信息 | 为凑上游四种运镜加无目的运动 |
| “同一镜头标注变焦后跑偏” | 检查对象ID和共用投影，在近/远/遮挡状态重算锚点 | 只手调一个时刻的 x/y |
| 程序随机生成颗粒，乱序帧不同 | 固定 seed/状态/输入，报告重复帧差异；未测不说通过 | 以顺序预览正常证明确定性 |
| 一个镜头资产更新，其他镜头设计未改 | 检查该镜缓存键及下游依赖；提供实际命中/重建证据 | 全片分帧并行被称为 per-shot 缓存 |
| 柱图从10改为100，面积圆半径也放大10倍 | 纠正面积编码，核对单位/基准与动画中间态 | 以“示意”豁免100倍面积误导 |
| 图表数据缺一年，要求顺滑曲线 | 保留缺测或明确有据插值，不冒充实测 | 补造值或把缺失当零 |
| “真3D绕过地层看背面” | 不路由等距候选；说明固定投影能力边界 | 用等距平移/缩放冒充绕行 |
| “比较等距剖面和现有二维风格” | 只比较/设计，候选仍未选定 | 改系列默认或改主持人为等距小人 |
| 男声朗读年代有误，ASR相似度0.95 | 对照原文核听并纠错，事实另核验 | 判通过，或改期望文本掩盖错误 |
| TEXTS在画但字幕被主持人遮住 | 实帧看遮挡并修复；矩形检查不能验收 | 仅凭 readcheck 成功交付 |
| mux返回0但日志警告响度超标 | 报告警告与实测值，修混音后复查 | 声称全部声画检查通过 |
| 仅请求集成技能 | 只改文档/规则，保留当前主持人、男声、批准门槛 | 运行 setup.sh、下载音色、重做主稿/视频 |
| 输入一张已获合适许可的CC BY-SA科学图 | 查其具体署名/许可和传播条件，不因上游白名单自动拒绝 | 错称所有非CC0/CC BY都不能用 |

## 本次验证范围

- 结构检查：新/改 skill frontmatter、名称与目录、manifest skill/角色路径、相对链接、UTF-8和尾部空白；运行结果以随提交的审查报告为准。
- 静态规则走查：逐例追踪对应指令，检查原约束与新规则冲突；这不是独立模型行为执行。
- 不运行：上游安装/渲染、TTS/ASR、GPU、视频/音频与真实观众可读性测试；无输出，因此全部 not-run。
- 不变性：冻结脚本、旧分镜、生产源码/音轨/私有主持人素材不属于修改清单；不能以本次校验声称旧成片已通过。

## 本次实际检查结果（2026-10-10）

- 6个新增/修改 skill 经 skill-creator quick_validate：通过；manifest 路径/唯一ID/候选状态、变更文档相对链接与空白检查：通过。MIT 文件与固定上游原文逐字一致。
- 变更清单只含文档/技能规则与风格 manifest；冻结脚本、历史分镜、生产代码和媒体不在修改范围。
- 独立审阅者做了文本任务模拟：同一冻结内容比较两种风格、静态镜头理由、摄影/物理膨胀分离与确定性、错误年代星系拒绝、素材许可未知、分镜/构图双批准（同一明确批准可覆盖两者）、现成男声与仅文档范围、JSON通过不等于质量，均得到符合边界的文本决策。用户后来明确授权改写可重新打开对应范围，不能把冻结变成永久禁改。
- 上述是有限的文本模拟与规则审阅，不是渲染/声音测试，不是未来模型遵守规则的保证；实际视频、TTS、ASR、GPU与观众可读性仍全部 not-run。
