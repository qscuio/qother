# 新风格技能编写模板

这是编写约定，不是可发现的第四种技能。新技能目录名使用 earthstory- 加简短小写连字符名称；frontmatter 的 name 与目录相同，description 说明本系列的具体风格及触发场景。

正文按以下顺序填写具体决策，不只保留标题：
1. 状态：proposed-unvalidated，注明提出者、试验范围与仍需用户选择。
2. 共享输入输出：链接 docs/style-system.md、docs/storyboard-template.md；说明渲染能力单独验证。
3. 色板：具体色值、主辅色关系、强调色数量与文字对比要求。
4. 材质与形状：纹理/粗糙度、轮廓规则、比例和禁止混用的视觉语言。
5. 人物身体与场景：全身比例、头颈连接、接地方式、资产复用、历史环境一致性。
6. 灯光：二维绘制明暗或三维主补光、阴影、曝光与跨镜连续性。
7. 摄影：透视或正交、允许运动、幅度与读图停顿。
8. 动作与缓动：事件的起止状态、物理约束、时长建议及真实工具支持边界。
9. 禁止缺陷与 QA：具体可观察失败、抽帧点与动态检查，而非笼统“高质量”。
10. 项目约束：完整原始向导、16:9、无假口型；位置/尺寸、现成男声与本次不启用声音克隆遵循 docs/production-style.md 当前制作配置；若用户后来明确修改，应更新本系列规范与资产而非暗中改值。

同时写一个独立 docs/agents 角色说明：明确输入、职责、交接物、阻塞处理、调用示例和完成标准。角色说明不等于部署配置。更新 style-manifest.json 后检查相对链接和各风格状态，避免把模板登记为实际风格。
