# 地球往事：统一制作流程

这是跨阶段制作的共用入口。配置见[production-style.md](production-style.md)，分镜字段继续用[现有契约](storyboard-template.md)，技能分工见[制作编排 skill](../.agents/skills/earthstory-production/SKILL.md)。流程文档和机械验证器不代表运行能力、内容或视觉质量已通过；本次门槛修订不改冻结作品或已交视频。

## 当前项目的继续权限（2026-10-10）

用户已明确要求本项目“不要等我批准”。分镜、构图关键帧与样片不再逐项等待用户点头：执行者完成内部事实/视觉/声画关卡后，在现有任务范围内继续制作，并主动交付结果与重要阻塞。用户审阅可随时提出修改，不作为常规流水线阻塞。

记录 proceed_authority=delegated-proceed、这条用户指令的日期/引用，以及独立 QA 的 pass/fail/not-run；只有用户确实认可某个具体版本时才另记 user-approved，绝不把授权继续伪装成用户看过图或通过质量验收。历史批准/未批准记录保留原状。该授权不改冻结正文、不扩大身份重建、费用、私有素材外传或对外发布权限；这些仍按原任务与必要确认处理。

## 先锁身份、覆盖，再按实际质量组装

1. **剧本身份**：以对应冻结正文的准确标题/哈希为准，核对封面、标题卡和视频内章节称谓。当前文本是《地球往事｜序章：地球的来处》；历史预览烧录“第一章”是待修正误称，不能因此重分章节或改稿。封面更新不代表视频内标识已更新。
2. **内容与视觉覆盖**：为每段及其主张记录旁白cue、镜头和要解释的概念/机制。分别核验正文/字幕完整与画面确实解释；有全部19段声音不能证明19段画面达标。镜头数量和具体视觉语法按任务决定，不新增百科范围。
3. **逐段放行**：完整范围组装前复核各段内容、视觉质量及相关连续性；当前序章以已有P10作制作质量对照，其他材质不须模仿粒子盘。fail、not-run、blocked及缺失证据阻止完成质量放行。可以在用户要求的范围内制作明确标注缺陷的预览，但不能称“已完成/已修好”。内部复核通过即可按delegated-proceed继续，不恢复逐段等待用户批准。

这些字段集中在[身份、覆盖与质量台账](../.agents/skills/earthstory-production/references/identity-coverage-gates.md)，由`scripts/validate_production_gate.py`机械检查标题、哈希、段落与映射引用；实际内容/视觉审查由人或agent完成并记录证据。机器通过只证明台账结构和所声明状态一致，不能代替看片、核听或语义判断。现有storyboard v1保持不变。

## 从当前证据继续，不重启全部工作

每次先核对任务范围、现有脚本/资产/音频/审阅包版本、继续授权及真实审阅证据。单镜、静帧、方法更新各按自己的范围交付；不因完整流程存在就自动扩张到整集。没有输入的阶段明确阻塞，仍可并行做已授权且不依赖它的研究或方案工作。

| 关卡 | 进入条件与动作 | 交付与放行证据 |
| --- | --- | --- |
| 1. 事实和连续旁白 | 锁定对应正文的准确标题/哈希，不从目录名推断章节；根据来源建立主张、局限和 source_id；先写自然连续中文，再安排镜头。按写作流程核验与口读，冻结获认可版本。 | 干净正文、来源映射、冻结版本/哈希、未决事实。文本口读不是实际配音。 |
| 2. 早期声音与粗分镜 | 冻结正文后拆理解目标与状态变化；有授权时尽早试听现成男性普通话样段，检验语速、停顿和术语。已有同版音色批准可沿用。 | 粗分镜、声音规划、临时时长范围；未有实测音轨一律 provisional，不填伪实测帧界。声音服务/私人文本传输遵守本次授权。 |
| 3. 视觉与素材 | 选本镜主语法和实际候选渲染路径；锁主持人身份，按需做动作库。用真实输出比较构图，先定方向再精修起/中/末关键帧。 | 粗图只审叙事/布局；精修关键帧需可追溯图片与版本。分别标 generated-concept（生成概念图）、renderer-output（实际场景渲染）、external-reference（外部参考）。前两者也不自动等于科学复原证据。 |
| 4. 音轨对齐与时序锁定 | 获授权制作/取得实际旁白，逐字核听并修正对齐；把已确认内容和声音共同映射到镜头、字幕、动作和帧界。 | 实测音轨及哈希、句/字幕 cues、帧率与时间基准、同版分镜。无音轨只留临时规划；临时静音审阅不冒充最终时序。 |
| 5. 分镜与构图质量关卡 | 把每段/主张的cue、shot_id、理解目标和同版旁白/音轨、时段、动作/运镜、keyframe_id与实际构图组成可追溯审阅包，内部检查科学语义、构图、连续性与时序。 | 内部检查通过并有证据后按 delegated-proceed 继续，无需等待用户逐项批准。粗图、参考图或结构通过不替代真实画面检查；最终时序改变设计时重新检查受影响部分。 |
| 6. 按任务范围逐镜制作 | 在实际运行环境过能力关卡后，制作通过前序质量关卡的短样片；声画复核后按任务继续。每镜独立 manifest/缓存/版本，受影响镜头局部重建。 | 可解码片段、命中/重建记录、实际首中末与切点证据。生产视频制作前须通过第5关；纯合成技术测试只能在已授权的明确测试范围内，不能冒充生产验收。 |
| 7. 合成与完整声画检查 | 先确认所选各段内容/视觉/连续性审查与标题身份通过，不能只看编码统计；场景帧、主持人、中文标注/字幕按锁定时序合成；最终用实际旁白及获准音效/音乐混音、编码封装。 | 连续全速有声观看、逐字核听、帧数/规格/完整解码及峰值等实测报告；带证据的缺陷修复复查。未播放或未听到写 not-run。 |
| 8. 私人交付或另行发布 | 确认当前任务的交付对象与素材权利。 | 视频、审阅说明、可复现源配置；私人角色原图/独立 PNG 另交私有资产包，不能补进公开方法仓库。发布并非制作的自动副作用。 |

声音规划在前，最终 mux 在后。试听不能锁定整篇时长；有真实音轨后才能声画时间锁定。并行工作可提前准备视觉/素材，但不能跳过实测时序与质量关卡。

## 渲染路径按任务选择

- 真三维网页候选：Three.js 负责几何、相机、材质、光照和空间投影；Anime.js 可编排数值参数与图层时间线。字幕/主持人保留屏幕层，科学标注使用同一世界到屏幕投影。候选是否可用必须实测。
- 真三维离线候选：Blender 自己负责场景与帧渲染，沿用其时间驱动方法，不强行加入 Anime.js。已有获授权渲染继续按原任务进行，流程更新不触发重启或替换。
- 真正二维图解：SVG/Canvas 可表达关系、剖面、地图、定量信息；不能用平面缩放冒充明确要求的真三维。手绘材料、纸纹、图谱只是所选风格内的语法，不能替换空间语义。
- 人物资产：身份基准保持既定版本，内部质量通过的完整静态层、绑定或逐动作帧序列按各自能力使用；动作库、口型管线、场景引擎互不冒充。sprite-gen、手绘库和 Lemo 的取舍仍见各自记录，未因此安装上游服务。

Anime.js 不是 MP4 编码器。逐帧捕获、合成、FFmpeg 编码/混音是另行实现并测试的生产适配层；仅有 seek API 或可播放网页不证明可以稳定导出。具体可执行约定见[渲染接口](../.agents/skills/earthstory-production/references/render-contract.md)。

## 能力关卡与现有实现缺口

在将要使用的环境记录日期、实际引擎/依赖版本、字体、WebGL/GPU（网页三维需要时）、帧读取及编码器测试结果。分别报告 checked-pass、checked-fail、not-tested；不要从“有浏览器”、历史 GPU 状态或仓库代码推断当前能渲染。没有实际图像，不宣布构图通过。

失败先查该环境内已获授权的替代路径；换渲染方式不能暗改既定真实三维/视觉要求，也不能绕过访问拒绝。若需换机器、安装、付费、上传私有参考或超出任务范围，报告准确阻塞并请求所需授权。没有可用路径就停在方案/静帧证据，保留未验证项。

[现有 cosmic-origin 管线](../production/cosmic-origin/README.md)提供旧纸感二维逐镜缓存与末端合成实现。代码目前仍有 1280×720、左下主持人和字幕空底栏等历史参数，布局与表现力仍需按本次任务核对，不能因分辨率相同就直接沿用；当前预览任务使用 1280×720，1920×1080 不再作为此任务的强制条件。保留其缓存边界、音频/字幕哈希和实测 cues 思路，但新适配器、布局迁移、Anime.js/Three.js/Blender 对接及端到端验证须独立实施。本次只增加台账一致性校验代码，未修改或重跑媒体渲染，也未宣称已有完整通用渲染管线。

## 变更与交接

- 锁定脚本、分镜、构图、资产、音轨和执行配置的版本依赖。继续授权与质量记录含对象版本、范围和证据；具体用户批准另存，不能把授权继续当成用户已审阅。
- 镜头主要构图、相机、动作、时长或声音设计变化：更新审阅包，只使受影响质量记录及下游失效，内部重审后继续；无需重新等待用户批准。若改变冻结正文、身份基准或越过原任务授权，则先报告并取得必要授权。纯实现缺陷修复不改变设计时，记录复查即可。
- 缓存与质量记录是两种依赖图：全片时码平移若不改变镜内时长/内容，局部视觉缓存可保留；剪辑、字幕、音轨和受影响质量记录仍需检查。通用字体/材质/渲染变化使依赖它的镜头失效，不一概强制全片重画。
- 交接使用现有 storyboard + 独立制作记录，不改造 schema v1 让旧验证器假装理解新字段。最小记录含 shot_id、输入版本/哈希、音轨状态、时间域、渲染路径、继续授权/真实批准引用、输出/缓存键、QA证据、阻塞与允许下一步。

细项验收以[确定性与 QA 证据](../.agents/skills/earthstory-cinematography/references/determinism-and-qa.md)为准；结构、静帧、连续动态与声音/事实分别报告。它们没有可互换的“总分”。
