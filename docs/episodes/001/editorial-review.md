# 第001集：从资料串联到因果叙事

2026-10-09 · v1.1 → v2.1。编辑记录，不是旁白的一部分。

## 内容选择

本集的中心认识：行星形成既是材料的积累，也是材料在受热后重新分布。碰撞把生长与内部变化连在一起。先让读者跟住这条物理过程，再解释我们怎样为它定年。

比较过按形成过程讲述与从陨石证据倒叙两种组织。采用前者：读者先知道正在追寻什么，进入测年时更容易理解样品的意义。年代名称保留原任务范围，但移到主解释之后，缩短为导航。

## 模拟初读与修订

一个未获得大纲、研究说明和作者预期结论的独立文本评审，只读了v2.1的中间稿。它准确复述了尘埃聚集、碰撞加热、内部分层、样品定年的主线，也指出五处问题。这是模型模拟，不是真人测试；修改后的整稿未再次做独立盲读。

1. 尘粒反复聚散后直接跳到“大尺度”，漏掉核心桥梁。补查E03，加入颗粒与气体作用、高密度聚集与自引力收缩的解释模型，保留仍在研究的限定。
2. “怎样知道形成过程”问得过大，后文只讲年龄。把问题收窄到年代，并用E04支持的岩石记录缺失解释为何需要陨石。
3. 地质年代名称像突然进入另一堂课。缩短为晚段导航；因本集原任务包含四宙和层级，没有全删。这里仍有信息负担，留待读者反馈。
4. 金属和岩石分开后又总结两次。压缩为机制、命名与一个剖面落点，不再整段回顾全片。
5. “需要多少次相遇”许诺数量却没有回答。改成松散尘埃怎样成为整颗地球的真实解释问题。

## 编辑判断与限制

- 核心问题和因果：补上尘埃到较大天体的模型桥梁；形成与分层由撞击热联系起来。仍需用画面帮助理解气体与颗粒相互作用。
- 内容与表达：精简重复结尾、空泛重要性提示和假想反驳。硅酸盐首次出现时说明是岩石成分；其化学细节留到有需要的集数。
- 科学分寸：原来源逐项对照，改动较大的E03与E04重新查询；具体访问限制见事实核查。不把流畅度当科学验收。
- 阅读：主稿只留旁白；七个章节串起不同任务，镜号、来源和时间集中在伴随资料。只做Markdown文本与链接检查，没有浏览器渲染预览。
- 视听与制作：三风格同步到同一文本，原15秒刻度撤下。420秒只是预算；未配音、未真人朗读、未渲染，也未做运动或素材验收。
- 系列承接：不提前展开海洋或生命，结尾只预告月球解释。年代层级仍是最密的一处，保留为明确可继续讨论的编辑选择。

## 第一节《太阳周围的尘埃》局部精修 · 2026-10-09

按纪录片写作与去套话技能，仅修第一节，保留全片标题和第2—7节。先建立“今天的岩石材料来自早期颗粒”的联系，再交代云团收缩成盘、中央太阳与外围材料，最后用内侧高温解释固体组成。

- “散落的材料”没有说清对象 → “太阳周围的尘埃”：标题给出具体对象与位置，范围仍是第一节。
- 开头提前讲“颗粒相碰，黏住，又散开” → 只问尘埃怎样成为行星：避免重复第二节的机制；删的是预演，相应事实仍在第二节。
- “把时间拨回”“太阳也还年轻” → 直接标约46亿年前，连写收缩、变密和扁平：减少转场口令，让动作接续；保留约数，不给地球精确完成日期。
- 只说岩石、金属能留下 → 补出内侧高温下冰难保持固态：让材料选择有原因；E01、E02及交叉核查见事实记录。
