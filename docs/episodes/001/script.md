# 地球往事 001｜尘埃聚成一颗行星

旁白重写稿 v2.1 · 2026-10-09

## 一、散落的材料

脚下坚硬的岩石，它的材料曾经只是太阳周围的细小颗粒。颗粒相碰，黏住，又散开。这样松散的尘埃，怎样聚成了一整颗地球？

把时间拨回约四十六亿年前。那时，太阳系正在一团气体和尘埃中诞生。地球还没有轮廓，太阳也还年轻。

引力让云的一部分向内收缩。物质向中心汇聚，旋转的云在收缩中铺展成盘。盘的中央形成了太阳；周围留下的物质，则成为行星的材料。

靠近太阳的地方很热。岩石和金属能够以固体的形式留在这里，细小的颗粒在盘中运动。组成地球的固体材料，就在其中。

## 二、相遇，也会分开

两颗尘粒轻轻碰上，可能黏在一起。让它们结合的，是颗粒表面的相互作用。更多颗粒加入，团块就有机会长大。但碰撞也可能让它们弹开，甚至重新碎散。

怎样从反复聚散的颗粒，长成大天体？一种有证据支持的解释是：颗粒与气体相互作用，在局部聚得越来越密，随后在自身引力下收缩，形成更大的天体。这是一种解释模型，具体过程仍在研究。

这些天体的引力，又能改变周围物质的运动，使更多材料在碰撞中加入。积累下来的物质越多，天体就越大。科学家把这种增长叫作吸积。

## 三、碰撞带来的热

太阳周围，许多行星胚胎沿着各自的轨道运行，也彼此牵动。有的碰撞使它们合并，有的会剥离一部分物质。年轻的地球，正是在这样的合并与损失之间，不断积累材料。

岩石行星的形成，可以持续数千万年。一次碰撞结束，生长还没有结束。因此，地球很难有一个精确的“竣工日”。它的大小和内部构造，是在这段漫长的形成过程中一同发展起来的。

撞击带来新材料，也带来热。运动的能量在碰撞中转变，足够猛烈的撞击，能使大片岩石熔化。原本坚硬的物质开始流动，混在其中的金属，就有了向深处迁移的条件。

内部也有热的来源。一些放射性元素在衰变时释放能量；物质向深处下沉，也会释放能量。撞击和内部供热，共同影响着年轻地球中哪些地方能够熔融、哪些物质能够流动。

## 四、地球有了内外

在能够流动的区域，密度较大的富铁金属向深处迁移，汇入地核。相对较轻的物质留在外围，主体是构成岩石的硅酸盐。

原先混在一起的金属和岩石成分，开始分开。这叫作分异。它与地球的增长同时进行；新的材料还在加入，后来的碰撞也会继续改造内部。

向内，是金属汇聚的核；向外，是以岩石成分为主的外层。曾经散落在太阳周围的颗粒，如今聚成了一颗内部已经分层、表面仍然炽热的行星。

## 五、向岩石询问时间

这样的地球，形成于多久以前？寻找答案时，我们会遇到一个难题：地球上的岩石不断被改造，最早的记录已经残缺。刚才的形成场景，是依据证据制作的复原；要给它标出年代，还得回到保存至今的样品中。

岩石里藏着一种计时的办法。有些同位素会以已知的速率衰变成另一些同位素。测量样品里有关同位素的比例，科学家就能估算它记录下的某次事件，距今有多久。

但要读懂这只“时钟”，还得了解岩石后来的经历。它是否受过热、重新熔化，或者与外界交换过物质？这些经历都可能改变记录。测出一块岩石的年龄，还不足以读出整颗地球的年龄。

一些陨石保留了太阳系早期的物质记录。它们与地球同属这段形成历史，却保存着地球样品难以完整留下的线索。把两者的同位素证据放在一起比较，科学家就能把地球形成的年代缩小到一个范围。

地球年龄的常用估计，是约四十五点四亿年。开头说的约四十六亿年前，指的是太阳系形成的背景。这两个数字标记着不同的事情；地球的年龄，也不意味着所有材料在同一天集齐。

## 六、漫长历史的开端

有了年代，我们才能把这颗年轻行星放回地球的长历史中。那段最早的时期，有一个名字：冥古宙。

“宙”是地质年代中最大的分段，往下还有代、纪、世。它们层层包含，各段的长短并不相同。

从冥古宙向后，是太古宙、元古宙，再到我们身处的显生宙。此刻，我们仍停在这把时间尺的起点附近，地球刚刚获得行星的轮廓。

## 七、还会发生的相遇

太阳周围，还有其他天体在运行。对于年轻的地球，下一次碰撞，可能带来远不止体积的改变。
