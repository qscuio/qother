# 第001集《尘埃聚成一颗行星》：扁平矢量分镜方案

## 交付与选择边界

本稿是六分钟、24镜的制作前文字分镜，使用同一集的[共用脚本](script.md)与时间轴。它是候选比较方向，不替换纸感二维暂定基线，不表示用户已选择此风格。没有制作或渲染图片、动画、声音，也没有锁定渲染器、字体或通过视觉验收。预期仓库位置：`docs/episodes/001/storyboard-flat-vector.md`；配套 `storyboard-flat-vector.json` 为机器可读规划稿，仅通过演示模式做结构校验。

依据仓库真实技能 `.agents/skills/earthstory-flat-vector/SKILL.md`、`docs/style-system.md`、`docs/storyboard-template.md` 与 `docs/style-manifest.json`。本方案必须随共用脚本更改而同步更新，不单独改写事实与旁白。

## 视觉规则：关系在画面中发生

- 16:9，计划1920×1080、30fps。画布正交，物体可沿平面路径运行；不做透视旋转或假3D飞行。盘状结构的侧视/俯视使用明确的“剖面示意”“俯视示意”标签，经整幅替换切换，不把二维椭圆翻成立体圆盘。
- 纯色、不用照片、纸纹、渐变、金属反射、体积光或投影。背景暖白 `#F5F1E8`；结构与文本墨黑 `#27313B`；每镜最多青绿 `#397E82`、赭黄 `#CE9946`、砖红 `#AD5E50`中的两种强调色。
- 语义固定：赭黄＝被追踪的固体聚集物；青绿＝气体路径/气体区域；砖红＝热状态提示，不能与金属成分或特定矿物等同。铁质内部用墨黑及文字，硅酸盐层用赭黄及文字。颜色为编码，未依据真实观测复原颜色。
- 基本形：圆、短弧、带圆角的不规则多边形；同类粒子同一套轮廓；不随镜头重新生成不同对象。轮廓计划画高0.28%，约3px，局部放大后重算恒定线宽。非数据驱动大小变化须常驻“尺度示意”。
- 一镜一个主关系。以接近、接触、聚集、偏转、散开、重新组织等连续状态变化承载叙事；标签只解释正在发生的事件，不能以一页页图标或大段文字代替事件。
- 单段关系展开500–900ms平滑进出，不用弹簧和连续弹跳。长运动保留可读轨迹；文字与数值定值直接出现，不对年代数字滚动插值。主动作结束至少停留1秒。所有尺寸/时间/数量比未标单位或未经数据支持时仅作示意，不伪装为统计图。
- 可视范围建议x=0.06–0.94、y=0.08–0.79；字幕独立保留底部15%，字幕框[x=0.13,y=0.85,w=0.74,h=0.10]。文字字号暂定正文42px、次标签32px，须最终像素验收；不能宣称已可读。

## 完整向导兼容性决定（待审）

原蓝西装三维玩具向导保持原始完整形象，以独立角标合成在平面场景上。它可以保留自身原图的立体外观，但主场景不模仿其材质。这个混合呈现是否合适仍需用户审阅；不擅自重画成二维图标，不使用新身体替换，也不声称已达成风格锁定。

仅在S01、S12、S24作为有限提示节拍露出；其余镜头隐藏。可见时画高20%，拟定安全槽[x=0.025,y=0.61,w=0.12,h=0.20]，槽宽不是角色拉伸宽度，实际宽度按原始长宽比重新核验。头、颈、身体完整连接；只允许整个图层淡入/位移，默认静止，不拆头、贴嘴、关节重拼或伪造口型。共同契约要求每镜引用原始向导资产，引用不等于每镜可见；JSON另设`guide_visible`表达显示计划。原始资产、真实比例及权利依据尚未接入，不能进入生产。

## 声音与实现范围

旁白文案来自共用脚本，但音色状态统一为`DEFERRED`。本交付无音频、无临时合成声音。后续若制作，宇宙外景不添加可被误认作真实传播的轰响；可考虑低幅非写实配乐和非写实接触提示，须标明其叙事性质并获进一步制作授权。所有逐镜“声音计划”都只是文字预案，不代表已有文件或已选声音。
