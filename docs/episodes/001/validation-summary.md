# 第001集交付验证摘要

验证日期：2026-10-09。范围：脚本、来源登记、三风格文字分镜与 JSON 规划，不包含任何媒体制作。

## 实际通过的检查

- 共同脚本采用1.1版，1457个汉字；24镜连续覆盖0—360秒，三套均为1920×1080、30fps的规划规格。
- 三套的镜号、起止秒数、逐字旁白及source_ids逐项与scene-spine.json严格相等；Markdown逐镜包含同一旁白。
- 每套的来源ID、URL及支持范围与sources.json一致。来源类别按分镜契约映射为kind=factual，原细分类别保留在source_type；共用来源登记的分类不改写。
- 仓库现有验证器分别通过三套demo结构：纸感二维24镜／8项资产需求／9来源；扁平矢量24镜／6项资产需求／9来源；微缩三维24镜／11项资产需求／9来源。均为360秒。
- 时间轴无空隙或重叠，起止时间符合帧边界，镜号唯一，资产需求版本、来源引用、连续性状态、向导高度和字幕框位符合共享契约。
- 对每份规划稿加--production，均被正确拒绝：production required; demo rejected。另在内存副本仅将mode改为production，再检查时均被全零资产哈希拒绝：demo asset hash rejected。没有为通过检查虚构真实哈希。
- 现有测试脚本通过有效样例与16个拒绝样例。
- 新增分集文档以及修改后的README、大纲中的Markdown相对链接全部检查可解析；未将规划素材路径伪装成已存在的文件链接。

## 可复现命令

在仓库根目录执行：

```sh
python scripts/validate_storyboard.py docs/episodes/001/storyboard-paper-2d.json
python scripts/validate_storyboard.py docs/episodes/001/storyboard-flat-vector.json
python scripts/validate_storyboard.py docs/episodes/001/storyboard-miniature-3d.json
python scripts/test_storyboard_validator.py
```

预期失败检查：对上述三个分镜命令分别追加 --production。此阶段如果生产校验直接通过，反而应检查是否错误填入了生产状态或伪造资产字段。

## 编辑复核

- 没有将太阳系约46亿年前的形成背景、冥古宙时间尺起点4567Ma、地球约45.4亿年的年龄估计混成同一时刻。
- 吸积包含黏附、破碎、气体作用及后期引力参与；没有全部碰撞必然增长或尘埃瞬间吸成地球的表达。
- 升温、吸积和分异相互交织；没有套入现代大陆、成熟地壳或现代固体内核结构。
- 同位素测年保留形成／保存条件与不确定性，不以单块最古老岩石或碳14直接测地球年龄。
- 第24镜停在碰撞前，只预告月球起源的重要解释，不提前播放月球、海洋或生命形成。
- 三套在构图、材质、事件运动与摄影上有可辨认区别；科学事实、旁白和时轴不因风格改变。

## 尚未验证与制作缺口

- 360秒是剪辑预算，尚未录音或试读；均匀15秒镜格用于比较，最终节奏须实测并同步修改三版。
- 图像、模型、原始向导、字体、音轨、绑定、口型及视频均未在本包生产或验收。
- 没有运行渲染引擎，没有逐帧观看成片，没有证明制作耗时、实际字幕可读性或音画同步。
- JSON中的资产路径、plan-v1与全零哈希仅锁定需求；intact=true是完整角色的制作要求。验证器不读取真实图片，不能证明图片完整、资产存在或权利已获许可。
- 来源的事实核验范围与访问局限见[fact-check.md](fact-check.md)，包括USGS年龄页直接访问403、官方搜索正文可检索的情况。来源链接不等于素材使用许可。
- 此包可进入内容与视觉方向评审，不能视为生产通过或已交付动画样片。
