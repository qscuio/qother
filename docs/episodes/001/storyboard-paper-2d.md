# 第001集《尘埃聚成一颗行星》｜纸感二维分镜方案

## 交付状态

本文件是可审阅的文字分镜与制作计划，不是动画样片。本轮不生成图片、视频或音频，不安装渲染器。共同脚本、镜头ID、时间和事实来源与另两种风格相同；只改变画面表达。画幅计划1920×1080、16:9、30fps，24镜头共420秒；不是已输出媒体的规格证明。

执行规范：[纸感技能](../../../.agents/skills/earthstory-paper-2d/SKILL.md)、[共享分镜契约](../../storyboard-template.md)、[风格清单](../../style-manifest.json)。这些规范已实际阅读；本方案未经过运动样片或用户视觉验收。

## 导演原则：纸层承载形成过程

- 纸层不是实体宇宙材料。星云、气体、尘埃、热量和引力均以剪纸轮廓、透明度、疏密和运动路径示意；不画成可在真空中飘落的碎纸，也不以纸张折痕解释物理成因。
- 前层用于少量近处遮挡与尺度参照，中层承载事件，后层稳定提供空间。远近层通过遮挡、尺寸层级和低对比区分；阴影只说明画面层次，不声称真实宇宙存在统一侧光。
- 每镜都必须有事件起点、变化、结果；关键是密度改变、碰撞结果、材料分布和截面演化。摄影只辅助读图，不以重复平移和缩放冒充动画。
- 镜头按新版旁白分配变长预算；内部节拍待配音实测，不能机械套用旧版15秒网格。

## 色板、材料、灯光与运动规则

- 纸底 #E9DFC7；轮廓/深空 #403A31；岩尘/热区强调 #A8754F；冷区辅助 #69765A。单镜只使用一种强调色，暖区镜头不再引入饱和绿色。角色蓝保留原图，不扩散为科学数据编码。
- 同一细纸纹密度锁定在屏幕空间；主物体2–3档明暗，边缘略不规则、转角圆缓。禁止照片星空、塑料球高光、写实火焰与剪纸混用。
- 统一绘制左上柔光与窄叠层阴影；透光热区是抽象色块，不能从阴影推断真实天体温度或光照。避免频闪、爆闪与过强粒子闪烁。
- 正交/平视为主。运动镜头只选一种主摄影动作：推近总量≤6%，横移≤画宽3%；视差各层相对位移≤画宽3%。即便较长镜头也采用比技能4–8秒建议更保守的总幅度，不逐段累加。俯视盘面到剖面用明确切换，不伪装成真实3D绕行。
- 事件动作平滑加减速；轨道粒子不随意停走。开镜与结尾保留约0.5秒读图，持续轨道允许继续运动，信息标注保持稳定。
- 字幕预留底部15%。正文关键事件在x=0.15–0.92、y=0.08–0.80。向导仅首尾和必要尺度说明可见；约画高20%，左下偏上；完整头颈躯干同一原图静止，不拆头、贴嘴或承诺口型。未取得原图之前，不画替代人物。
- guide.bbox宽度只是预留槽位；真实原图必须等比适配，不能按槽位拉伸。所有镜头仍引用同一待取得的完整原图需求，隐藏镜头不实际显示人物。

## 声音与制作边界

所有镜头的旁白仅为共同文本；声音状态为deferred。SFX/音乐仅列未来可选制作方向，当前统一静音占位；不生成声音、不选择音色、不承诺口型。未来配音定稿后须验证每句语速与停顿，420秒是计划时长，不是已实测旁白时长。

JSON使用契约现有mode=demo，因为尚无真实素材。零SHA-256只是明确的无文件占位标记，version=plan-v1锁定需求描述而非资产字节；intact=true是完整原图的要求，不是已核验图片。未来生产必须取得素材与权利、计算真实哈希、替换清单、检查像素及来源支持，再改production。不得直接拿本JSON宣称可渲染或生产通过。

## 三个关键帧文字设计（非已生成图）

### K1｜云的局部收缩：广阔感来自留白

画面深褐底上，六至八片低对比暖灰纸云错叠，边缘不做剪纸桌面卷翘。中景略偏右的密度核在约画宽45%范围内，周围细颗粒的方向和疏密指向它；不是整片星云均匀吸向一个点。左前景只有一片暗轮廓，以遮挡建立层次；远景纸云固定。小标“示意：非真实比例”放右上。颗粒轨迹与字幕不交叉。关键帧希望读到的是“局部密度改变”，不是一次爆炸。对应S05。

### K2｜吸积盘：椭圆叠层，不是平面饼图

厚薄不等的半透明纸环在中景形成扁盘，中心亮核偏右；椭圆前半圈遮挡内侧，后半圈从亮核后穿过，以遮挡读出倾斜关系。盘内少量颗粒各自沿环向路径行进，同时保留极小径向变化；禁止所有粒子齐步转动。只用土赭标高温区，其他区域降饱和；标签说明温度/尺度为示意。前景最多三块模糊轮廓状颗粒，绝不落向画面底端。纸影宽度统一，不能看起来像一叠桌面餐盘。对应S06。

### K3｜热的早期地球：用截面讲内部变化

主体占画高约65%，右侧开放一块剖面。岩石外层是深褐纸壳；内部赭色区使用2–3档平面色阶，不做发光玻璃球。高密度材料的抽象块沿短向心路径汇聚，浅色材料区域向外重排；用低对比曲线提示路径，不能成为整齐钢珠漏斗。外部保留少量尚未吸积的岩块提醒“仍在形成”，不画蓝海、现代大陆、植物或现代月亮。底部字幕独立；若本镜需要向导，只用已核验完整原图静态说明“剖面/非比例”，不可遮剖面。对应S14。

## 资产需求与版本锁定方式

本轮只有资产清单文字，无图片、纹理、角色、模型、音频或字体文件。以下每一项都需要未来制作或取得；plan-v1仅表示需求版本，不能当资产验收版本。

- guide-original：用户已有同一份蓝西装完整原图；需取得原文件、使用依据、原尺寸/比例、真实SHA-256，核对头颈躯干与轮廓。不得重生成人物顶替。
- paper-surface：统一细纸纹与四种基础色，检查屏幕空间颗粒尺度及纹理使用权。
- cloud-layers：分层云轮廓与疏密遮罩；不得做出纸屑有空气阻力的物理暗示。
- disk-layers：倾斜椭圆盘、中心亮核、内外区遮罩；提供遮挡次序和科学示意标记。
- dust-clusters：大小分档颗粒、孔隙团块以及碰撞后的不同结果；重用同一代表颗粒轮廓便于追踪，但明确不是同一粒尘埃的真实履历。
- rock-embryos：不规则岩块、星子/胚胎轮廓和相对运动路线；尺度切换用标注，勿暗示按真实尺度同框。
- earth-cutaway：热原地球、层状剖面、内部材料分布状态；不含当时不存在的现代地貌。
- evidence-annotations：年代/术语/示意标签与抽象样本剖面；实际样品图不在本轮需求中，避免伪造观测证据。

未来每项真实资产生成不可变版本；每镜引用asset_id+version，替换必须更新全部使用处。若使用字体，须记录字体文件/授权/版本，先做中文缺字检查。

6. 生产前必须以真实文件哈希重建清单，再运行--production；结构校验之外仍要逐帧与事实审查。
