# 研究来源与核查规范

本页汇总工作大纲使用的公开资料入口。来源编号与 [完整系列大纲](series-outline.md)、[分集数据](../data/episodes.json) 对应；机器可读索引见 [sources.json](../data/sources.json)。这些入口用于选题层面的校准，不能替代正式脚本的逐句核查。

## 资料使用原则

- 地质年代优先对照国际地层委员会的年代地层表，记录版本。年代边界可能随研究更新，不把旧表与新表的数值混用。
- 科学与历史解释优先查阅研究机构、大学、博物馆、档案馆、原始史料和学术研究。综合资料可帮助定位问题，重要结论须回查出处。
- 把确定事实、主流解释、竞争假说与艺术复原分开记录。争议年代使用范围或约数，避免给出虚假的精确性。
- 每集开稿时建立事实清单，记录具体说法、对应页码或章节、链接、查阅日期以及是否有争议。
- 公开可阅读不等于可自由转载。图像、音乐、影片与长段文字须另外记录授权条件；链接到资料不代表获得素材使用许可。
