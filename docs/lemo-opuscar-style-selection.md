# Lemo-Opuscar 风格规范吸收范围

## 决定与阅读深度

以固定版本 a75e2b3384cded87955c8743b5a59db06ea491a8 的43种基础风格为范围，不把另一个98部影片专题目录混进计数。已读43项索引及README中文简介；进一步读取下表10项STYLE.md的视觉材质、色彩、字体、运动、摄影和相关缺陷规则。其余33项只做简介层级筛选，不能声称逐项精读或运行过演示。

新增两种独立候选skill/角色：科学结构图（局部机制/剖面），博物志铜版图谱（古生物/化石/器物）；补强现有纸感二维、扁平矢量、微缩三维、等距信息图。它们都不是已选系列方向，也未获成片验收。真实三维宇宙场景仍需相应三维方案和实物验收，结构线图、暗色软件发布模板均不能代替。

## 一种风格的一套语法

每镜先确定一个主风格，再固定色彩语义、材质、字体类别和尺寸、布局、光向、摄影、运动与转场。不能从每种参考各取一件装饰造成拼贴。字体仅列可用类别，采用前验证本机已有授权字体和中文覆盖；本包没有字体下载。数值是本地候选起点，实际静帧/手机缩览/动态结果优先。

上游中的女声、字体文件、角色/演示资产、引擎、安装器、品牌实例及自动出片流程均未引入。当前原始完整男性主持人、满幅场景、字幕叠加、男声普通话和分镜/构图双审批仍以production-style.md为准。MIT文本沿用docs/third-party/lemo-opuscar-LICENSE.txt；演示第三方资产不因仓库MIT而获得授权。
