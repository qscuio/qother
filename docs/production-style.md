# 画面与制作规范

## 当前制作配置（2026-10-10）

当前主持人参考布局优先于旧样稿和候选 skill 中的试制值；这不代表完整构图关键帧已获批准：1920×1080 时，原始短发、深蓝休闲西装男性主持人置于右下圆形角标，直径 250 px，外接框左上角为 (1622, 790)。完整原始角色置于该区域，不拆头贴嘴；不预留整条空侧栏或空底栏；字幕安全区叠加在场景上并避让关键内容，不挖空画面。其他分辨率须重新检查安全区和遮挡，不把 250 px 或旧约20%比例当普适公式。原始角色文件不随公开方法包发布。

当前采用现成男性标准普通话，实际音色质量仍需试听验收；本次不启用声音克隆，若另行授权再评估。不能回退到上游默认女声或把已有选型等同成片合格。

冻结脚本不静默改写。视频制作前，用户必须明确批准对应版本的分镜和构图关键帧；两者缺一停在审阅包。分镜缓存/局部重建、真实声画 QA 仍须逐项验证，方法文档不证明已完成。

## 画面结构

横屏是主要方向。历史场景铺满画面，承担地点、时间、环境与事件的信息；讲解角色位于下方角落辅助引导，使用上面的当前右下角标配置。角色、字幕与平台界面元素须避让关键证据、地图和主体动作。

讲解角色暂采用短发、深蓝休闲西装的风格化玩偶形象。该形象是视觉方向，尚不代表自然口型和动作已经完成。

## 场景表达

- 随讲述推进切换场景、地图、时间轴、剖面与必要图解，避免以静态角色长时间覆盖单一背景。
- 地质章节同步呈现时期名称、约略年代、海陆格局、气候与代表性生命；不要把不同年代的物种与地貌随意拼在一起。
- 历史章节检查服饰、建筑、器物、地图边界与文字的时代适配性。
- 对古环境、生物外观和历史场景的复原，区分已有证据与艺术推测；需要时加上“示意”或“艺术复原”说明。
- 图像生成与动画效果不能替代事实核查。生成的文字、地图和标注必须另行检查。

## 角色质量底线

角色需要完整、连续的头颈与身体结构。避免头身分离、颈部接缝、粗糙嘴部贴片、模糊局部和突兀变形。自然口型、表情和身体动作是待验证项；正式制作前需先完成短样片测试。

## 旁白与字幕

旁白遵守上面的男性标准普通话配置，具体音色与输出仍须试听。表达以自然、清楚的口语为目标，保留必要停顿，不采用机械或播音式的连续朗读。字幕与关键术语须统一译名、年代单位与标点；画面中数字和专名必须与旁白及资料一致。

## 建议制作顺序

选题与资料核查 → 连续脚本与冻结版本 → 分镜及构图审阅包 → 两者明确获批 → 按批准版本做短样片 → 声画复核 → 完整制作与素材授权复核。实质设计修改先重审受影响部分。

这是一套建议流程，具体工具、软件、配音服务和生产排期尚未选定。

## 样片验收清单

- 本集核心问题明确，观众能理解时间与地点。
- 画面和旁白讲的是同一件事，没有明显时代错置。
- 讲解角色比例合适，不抢占场景；口型和动作若未实现，明确按静态测试评审。
- 字幕清楚，术语与年代可读；画面在平台常见观看尺寸下仍能理解。
- 关键事实可追溯，争议和推测有适当说明。
- 引用、图片、音乐与其他素材的权利状态有记录；未确认授权的素材不进入正式发布成片。

## 分风格规范与分镜

完整规范见 [风格体系](style-system.md) 和 [分镜模板](storyboard-template.md)。纸感二维保留为历史试制方向，不再作为宇宙开头默认。当前宇宙开头正在比较暗色科学图解与浅色图谱方向，两者尚未选定或批准，系列亦无最终统一风格；扁平矢量、微缩三维与等距信息图均为未验证候选。每种风格有独立仓库 skill 和角色说明，统一引用事实来源与版本化素材；这些文档不代表运行中的 agent 或已安装的渲染工具。工具选择依据见 [动画工具研究](animation_skills_research.md)。


## 人物素材工作流

采用[独立人物动作素材 skill](../.agents/skills/earthstory-character-assets/SKILL.md)准备和审查素材。先保留足够大的完整主参考与原始单帧，沿用已批准半身取景（头颈肩及上半身连续），不补腿脚或缩成全身小人，再统一尺度、支点和透明边缘；上面的250 px圆形只在最终合成施加，不能作为生成时意外裁断头颈或关键手势的目标；批准构图中的有意半身下缘裁切仍然允许。每个获批动作锁定独立资产版本，替换/重排需重审；未完成动态验收时仍按静态或完整图层处理。动作素材批准不能代替同版分镜与构图批准。
