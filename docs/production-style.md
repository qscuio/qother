# 画面与制作规范

## 画面结构

横屏是主要方向。历史场景铺满画面，承担地点、时间、环境与事件的信息；讲解角色位于下方角落辅助引导，暂以约 20% 画面高度为试制比例。角色、字幕与平台界面元素须避让关键证据、地图和主体动作。

讲解角色暂采用短发、深蓝休闲西装的风格化玩偶形象。该形象是视觉方向，尚不代表自然口型和动作已经完成。

## 场景表达

- 随讲述推进切换场景、地图、时间轴、剖面与必要图解，避免以静态角色长时间覆盖单一背景。
- 地质章节同步呈现时期名称、约略年代、海陆格局、气候与代表性生命；不要把不同年代的物种与地貌随意拼在一起。
- 历史章节检查服饰、建筑、器物、地图边界与文字的时代适配性。
- 对古环境、生物外观和历史场景的复原，区分已有证据与艺术推测；需要时加上“示意”或“艺术复原”说明。
- 图像生成与动画效果不能替代事实核查。生成的文字、地图和标注必须另行检查。

## 角色质量底线

角色需要完整、连续的头颈与身体结构。避免头身分离、颈部接缝、粗糙嘴部贴片、模糊局部和突兀变形。自然口型、表情和身体动作是待验证项；正式制作前需先完成短样片测试。

## 旁白与字幕

配音方案待定。表达以自然、清楚的口语为目标，保留必要停顿，不采用机械或播音式的连续朗读。字幕与关键术语须统一译名、年代单位与标点；画面中数字和专名必须与旁白及资料一致。

## 建议制作顺序

选题与资料核查 → 单集提纲 → 分镜 → 短样片 → 脚本与视觉修订 → 完整制作 → 史实、音画与素材授权复核。

这是一套建议流程，具体工具、软件、配音服务和生产排期尚未选定。

## 样片验收清单

- 本集核心问题明确，观众能理解时间与地点。
- 画面和旁白讲的是同一件事，没有明显时代错置。
- 讲解角色比例合适，不抢占场景；口型和动作若未实现，明确按静态测试评审。
- 字幕清楚，术语与年代可读；画面在平台常见观看尺寸下仍能理解。
- 关键事实可追溯，争议和推测有适当说明。
- 引用、图片、音乐与其他素材的权利状态有记录；未确认授权的素材不进入正式发布成片。

## 分风格规范与分镜

完整规范见 [风格体系](style-system.md) 和 [分镜模板](storyboard-template.md)。纸感二维为暂定基线，现有试验只验证构图布局；扁平矢量与微缩三维为未验证候选。每种风格有独立仓库 skill 和角色说明，统一引用事实来源与版本化素材；这些文档不代表运行中的 agent 或已安装的渲染工具。工具选择依据见 [动画工具研究](animation_skills_research.md)。
