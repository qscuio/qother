# 宇宙起源总览：事实核查

核验日期：2026-10-09。对象：[当前连续旁白](script.md)。本篇是序章总览，覆盖大爆炸至地月系统形成；不是六个互斥的完成阶段，不据此重编120集大纲。

[来源登记](sources.json)保留实际复用的 E02、E03、E04、E06、E09；新增宇宙、恒星、银河系材料用 C01—C07。段落以首句定位，正文不插入来源代码或编辑说明。

| “细小颗粒发生碰撞” | 团聚/破碎与气体相互作用支持的局部集聚模型；正文保留“一种模型”“足够密”“可能”。不是唯一已复原的地球制造工序。 | E02、E03 |

| “年轻地球的周围”至“月球的起源” | 约4.5Ga大碰撞为主流解释；撞击体、过程与聚集时长仍研究。高温熔融记录、月地岩石化学相似性是检验线索，不声称单个证据独自证明唯一模型。 | E09 |
