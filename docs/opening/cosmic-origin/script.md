# 地球往事｜序章：地球的来处

约一百三十八亿年前，宇宙里还没有一颗星，也没有一块石头。

空间正在膨胀。早期宇宙炽热、稠密，光不断与带电粒子相遇，难以走远。随着膨胀，温度逐渐降低。我们所说的大爆炸，描述的正是宇宙从这种早期状态展开的历史。

约三十八万年后，电子能够与原子核结合，形成中性原子；光终于可以穿过漫长的距离。那时留下的辐射，今天仍能被探测到。

宇宙渐渐冷下来，却还没有星光。散布其中的物质，主要是氢和氦。它们可以聚成恒星，但要组成一块岩石，还缺少许多东西：氧、硅、铁，以及制造这些元素的漫长岁月。

气体并不是处处一样稀薄。有些地方稍微密一些，引力便把更多物质聚向那里。云团向内收缩，中心越来越热，直到氢的原子核开始结合，变成氦，并释放能量。这种反应叫核聚变。恒星由此获得了持续发光的能源。

在宇宙最初的几亿年里，第一批恒星逐渐出现，早期星系也在形成。气体、恒星汇聚在这些不断生长的系统中。大片没有星星的空间里，开始有了成群的光。

恒星的内部，物质还在变化。氢转变成氦；随着恒星演化，有些恒星能进一步制造碳和氧，质量足够大的恒星还能制造硅、铁等元素。今天岩石里的许多成分，最早是在这样的高温中形成的。

这些物质并不全都留在恒星里。一些恒星会向外抛出自己的外层；有些大质量恒星在生命末期发生超新星爆炸，把内部的物质抛向周围。新产生的元素混入星际气体，成为下一批恒星和行星的材料。

银河系就在这样的宇宙中长大。

它最早的形成可以追溯到一百三十多亿年前。此后的漫长岁月里，它不断汇集物质，也与其他星系合并。

星系在生长，星系中的恒星也在更替。新的恒星形成时，周围的云团已不再只有早期宇宙中那样简单的成分。气体之间，混有前代恒星释放的元素，也有含着这些元素的细小尘粒。

约四十六亿年前，银河系里的一片气体和尘埃云开始收缩。

云团一边转动，一边向内聚拢，逐渐形成扁平的盘。大部分物质汇向中央，孕育太阳；留在周围的物质，绕着年轻的太阳运行。太阳还在形成，周围的盘里，行星也开始生长。

那时尚没有今天这样彼此分明的八大行星。靠近太阳的地方，温度高，难以留住冰，固体材料主要是岩石和金属。后来构成地球的物质，就散在其中。

细小颗粒发生碰撞，有些黏合，有些弹开或破碎。碰撞并不总能使它们长大。从颗粒到更大的天体，中间的过程仍在研究。

一种模型认为，颗粒与气体相互作用，能在局部聚得更密。聚集足够密集时，这一团颗粒可能在自身引力下坍缩，形成更大的小天体。

这些天体继续碰撞、合并，逐渐长成行星胚胎。地球也是其中之一。它在一次次合并中增加质量，也会在猛烈撞击中失去一部分物质。这个过程延续了数千万年。

碰撞改变的还有内部。运动的能量转化为热，猛烈的撞击能使大片岩石熔化。金属和岩石成分获得了流动的条件：密度较大的富铁金属向深处迁移，相对较轻的岩石成分留在外围。

地球一边长大，一边有了内外。向内，是逐渐汇聚的金属核；向外，是以岩石成分为主的外层。

我们通常说，地球的年龄约为四十五点四亿年。这个估计来自地球样品与陨石等留下的同位素记录。它标出了地球形成的年代，却不能把漫长的生长压缩成某一天。

年轻地球的周围，仍有其他天体穿行。一次足以改变地球的碰撞，也可能解释月球的来历。

目前的主流解释认为，约四十五亿年前，一个较大的天体撞上年轻地球，把大量物质抛到周围。这些物质在地球附近聚集，形成了月球。撞击究竟怎样发生、月球用了多久聚成，仍在研究。

从月球带回的岩石，保留着高温熔融的记录；它们的化学成分，也与地球岩石有许多相似之处。这些线索帮助科学家检验碰撞的模型。月球的起源，连着地球尚未安定下来的早年。

到这里，曾经分散在星际的材料，已经聚成了太阳周围的一颗行星。另一些物质围绕它，成为月球。

地球仍然炽热。今天熟悉的大陆与海洋，还没有呈现出它们的模样。但从此以后，这些来自更古老宇宙的物质，会在同一颗星球上继续变化。
