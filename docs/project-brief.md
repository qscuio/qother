# 项目定位与创作原则

## 项目概要

《地球往事》是一套面向大众的历史与科学叙事视频。内容从地球诞生延伸到地质历史、生命演化、人类与文明，并逐步进入近现代世界。自然环境、生命与人的故事彼此连接，同时保留各领域所需的证据与解释尺度。

大纲暂按 12 卷、120 集组织，便于检查覆盖范围与叙事衔接。分卷、集数、边界和标题均可调整，不代表已经确定的制作或发布承诺。

## 内容目标

1. 建立清晰的时间感：观众知道事件发生在何时、持续多久，以及它和前后时期的关系。
2. 解释变化的过程：说明环境、生命、技术和社会结构如何相互作用，避免只罗列名词与年代。
3. 覆盖世界的多样性：在讲述人类与文明时，注意不同地区的并行发展、交流和差异。
4. 让知识进入故事：以具体问题、场景与证据组织叙事，不为了悬念制造不存在的事实。

## 准确性要求

- 地质章节明确区分宙、代、纪等时间单位；奥陶纪、白垩纪等名称须配合年代与环境背景解释。
- 年代采用一致的表达方式，并注明约数、范围与必要的不确定性；地质界线需对照权威年代地层表。
- 生命演化用分支关系表达，避免将其写成必然走向人类的单线阶梯。
- 历史叙事区分证据、主流解释与学术争议；不把复杂变化归结为单一人物或原因。
- 维基百科可作为检索起点，重要说法须回到研究机构、博物馆、大学、原始史料或学术研究交叉核查。

## 叙事与命名

标题要具体、耐读，并自然引出这一集的问题。避免空泛命名、低俗噱头、与内容无关的当代消费类比，以及无法由证据支持的绝对化说法。

旁白采用自然的口语节奏，允许停顿和轻重变化；保留解释的严谨性，避免播音腔和连续堆砌术语。必要术语第一次出现时，用简洁语言说明。

## 形式与阶段

发布方向为抖音与 YouTube，横屏为主要制作方向。单集 5–8 分钟可作为试制时的参考，尚未定稿。

当前优先任务是评审大纲和验证单集的表达方式。首集完整脚本、配音方案、角色动画方案和批量生产流程，均需要样片验证后再确定。
