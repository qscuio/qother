# 已确认方向与待定事项

此文件记录项目当前的创作决策，区分已明确方向、暂定方案与尚未解决的问题。

## 已明确的方向

- 项目名称为《地球往事》。
- 内容从地球诞生、地质历史与生命演化展开，延伸到人类、文明和近现代世界。
- 以事实准确为前提，明确解释地质时期及其环境与生命背景。
- 叙事和标题需要吸引力，也需要克制；不采用低俗、失真或过度迎合流量的表达。
- 发行平台考虑抖音与 YouTube，画面优先采用横屏。
- 历史场景是画面主体，讲解角色仅作辅助。

## 暂定方案

- 全系列暂按 12 卷、120 集编排，作为工作大纲供评审。
- 讲解角色采用短发、深蓝休闲西装的风格化玩偶形象，位于画面下方角落，高度约占画面的五分之一。
- 单集时长可先以 5–8 分钟试制，再依题材密度与观看体验调整。

## 已淘汰的方向

- 《地球历史》这一过于平淡的命名，以及《没有超市，人类怎么吃饱？》一类不符合本项目气质的开场选题表达。
- 角色占比过大，挤压历史场景的信息空间。
- 头部、身体与嘴部粗糙拼接的表现方式，包括颈部不连贯、模糊、明显嘴部贴片等问题。

## 待定与待验证

- 第一集最终选题、标题和完整脚本。
- 120 集大纲的取舍、分卷边界、篇幅与最终排序。
- 配音方案。
- 角色自然口型、面部表情、身体动作和完整绑定方式；目前角色仍为静态方案。
- 历史场景的动态实现、地图与时间轴表达，以及素材的授权与来源管理。
- 最终时长、制作周期与发布排期。

## 下一阶段的检查点

1. 审阅全系列大纲，处理遗漏、重复和跨度失衡。
2. 选定第一集，列出事实核查清单与资料来源。
3. 制作短分镜和视觉样片，验证场景、角色比例、字幕与口语叙事。
4. 样片通过后，再讨论完整制作与后续批量流程。
