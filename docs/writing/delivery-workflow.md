# 从材料到可交付正文

这是新写与深改的交稿流程，不是规定作品形状的模板。目标是把能在交稿前发现的问题留在内部解决，减少让用户逐轮指出基础问题；不能保证一次写作符合所有审美偏好。两句润色只做局部保义、顺读和上下文复核，不另造全篇方案。

## 1. 收窄任务，建立依据

用几行工作记录确定：给谁听、已知什么、这次要理解什么、篇幅与止点。区分读者不认识的名词和缺失的关系。列出承重主张及对应来源，标明观测／解释模型／未知、必要条件和范围；沿用现有事实记录，不重复建库。无支持的因果不能进入方案。

定声前查[参考登记](reference-registry.json)：只有明确接受的具体版本及获准范围才能作风格基准。“比上版好”不等于全篇获准。没有合格基准就按任务及现有反馈写，不索要每轮确认，也不假称已掌握用户最终偏好。

## 2. 先打通理解顺序，再写句子

为拟写段落各记一行：接住什么已知信息 → 要回答的新问题／段落用途 → 离开时读者多理解什么。只在存在断点时补记与相邻段的关系：时间、因果、证据、尺度切换或反例。不是要求每段问句开头，也不是把工作标签念进旁白。

检查下一段需要的对象、前提和尺度是否已出现。年代先后不能自动成为因果；证据段须说明它支持哪个判断，不能暗示已证明全部细节。并行过程保留重叠，不为线性好讲而改成依次完工。模型中的对象到下一段仍是模型对象，不能用“这些”悄悄接成确定历史。

若两段只靠“随后／因此／在这样的背景下”粘连，先找缺失关系：有依据就补必要解释；无依据就移动、删去旁枝或收窄主张。不得用更多过渡词掩盖跳步。开头承诺解释的问题，要在本篇范围内得到回答，或明确缩小开头的承诺。

## 3. 写连续正文，按语义修中文

先完成连续旁白，不逐段向用户索取许可。关键变化给足解释空间，过渡可概述；不用统一句长、固定段数或十五秒网格推着意思走。

拗口处先还原成“谁／什么，在什么条件下，发生什么，影响什么”，再重写。查动词与对象是否搭配，代词能否只有一个合理所指，修饰语是否紧贴被修饰部分，省略是否丢了动作或条件，书面语和口语是否无故切换。不能只凭音节顺口换同义词。“有了内外”听似简洁，却会把成分分层误成原先没有内外；应写准实际变化。详细操作见[手册](narrative-craft.md)和[诊断示例](deslop-examples.md)。

按意思安排重音、停顿与长短：条件与判断需要连读就保留长句；结果需要停留才短收。口读预审遇到回读时追查语义负担，不用全部剪短来消除问题。收束可以留余味，但压缩后仍要保住材料的来路与因果。

## 4. 分开审，合起来复核

初稿完成后先冻结一份净稿再审，不一边写一边宣布通过。完整稿／结构深改至少做一次独立文本审阅：可由另一位编辑或独立模型完成，给净稿、任务与核查所需来源，不给作者的辩护或期待结论。初读复述时先不给计划和预期答案；事实审查时再对照来源。没有独立审阅条件时明确记为作者自检，不能冒充独立通过。

- 逻辑审：从正文复述对象怎样变化、为什么换段，定位无前提的跳步、未回答的承诺及时间／尺度／确定性偷换。
- 语言审：只定位真正妨碍理解或使中文别扭的地方，给出原句、读者可能理解成什么、改动理由；已经自然的句段保留。不要为了显得做过工作全部换词。
- 证据审：对照承重主张，检查修订前后对象、条件、数值、来源身份及确定程度；尤其回看改动处前后段和结尾压缩。

同一独立审阅可分三次阅读，不要求部署三套代理。作者合并反馈，先修逻辑，再修语言，最后对修改处做证据复核与连续回读。通常一轮完整审阅加一轮针对修订的复核即可；若仍有阻塞，回到对应计划或材料环节，不能机械多轮改词。两轮后仍解决不了的缺口应明确报告原因和所需材料，不把带硬伤的稿件包装成已验收，也不要求用户替编辑逐条修句。

## 5. 按证据决定能否交稿

按[共同验收](editorial-rubric.md)判定。未解释的因果跳步、悬空承诺、错误指代、无依据的新事实／确定性、编辑提醒混入旁白，任一仍在都阻止“完成稿”交付。资料不足只能交待核稿及具体缺口。

简记本次实际解决的断点、保留的好文字和剩余限制，以句段证据说明为何已可读；不报文学总分、禁词零命中或笼统“逻辑清晰”。把记录放在既有审稿伴随文件，不污染正文。给用户的是净稿和少量有用结论，不是每一轮补丁。跨题材测试与真人阅读仍可能暴露新问题；只据实际结果更新规则。
