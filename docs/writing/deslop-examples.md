# 精修示例：改善表达，不改变证据

以下是本项目原创编辑示例，不是上游技能的示例转载，也不是新的科学证据。涉及第001集的表述仍需按该集来源登记核查。

## 1. 让动作承担解释

原句（第001集旧稿 S14）：

“在能够流动的环境中，密度较大的富铁金属向深处迁移，逐渐汇入地核；相对较轻的硅酸盐物质，构成外围的主要部分。”

问题：同一句同时交代条件、两种材料、相反位置和结果，后半句容易失去动作。

可改为：

“当内部物质能够流动，密度更大的富铁金属便向深处迁移，逐渐汇成地核。相对较轻的硅酸盐物质，主要留在外层。”

理由：先交代条件，再看一种材料的去向，最后形成对照。没有为生动添加速度、颜色或声音。

事实复核：保留可流动条件、相对密度、富铁金属、硅酸盐与“主要”。沿用第001集 E06 支持范围；不能把“外层”改成“今天的地壳”，也不能暗示一瞬间完成。放回正文时还须有吸积与分异交织的必要说明。

## 2. 有些词不该删

“地球的年龄通常说是约四十五点四亿年。”

“通常说是”可以依上下文压缩，但“约”不能为了果断而删。不能改成“地球诞生于四十五点四亿年前的某一天”，也不能把年龄估计当成过程的明确完成时刻。关键问题是精度与含义，不是有没有软化词。

## 3. 结构问题不靠换词解决

“尘埃开始聚集。这是一场壮阔的变化，深刻改变了地球的未来。”

问题不只是“壮阔、深刻”俗套，而是聚集如何推进、下一步发生什么都没说。把它改成“尘埃汇聚，开启了新的篇章”仍然没有解释。

修复应回到实际材料：若来源支持，交代颗粒相遇时可能黏住、弹开或破碎；若没有对应来源，先补查，不能当场添加一种让故事更顺的机制。本例用于展示编辑判断，不提供可直接当史实使用的新旁白。

## 4. 不为了证明做过工作而重写

一句话的对象、动作、限制和节奏已经清楚时可以保留。必要的因果连接、真实对比、术语或复述都有用途。编辑报告应解释为什么保留，而非用同义词替换制造改动量。
