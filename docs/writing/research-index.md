# 地球往事写作技能：研究与使用

首要交付是更好的内容：清楚的核心认识、顺畅的解释路径、具体而准确的中文。版式整理只帮助读者进入内容，不能代替创作。

## 三项原创仓库技能

- [内容与脚本写作](../../.agents/skills/earthstory-scriptwriting/SKILL.md)：选择角度与事实、构建叙事因果、写自然有表现力的中文旁白，并保留证据边界。
- [去套话与精修](../../.agents/skills/earthstory-deslop/SKILL.md)：对已有内容作有证据的语言诊断与定向修订，保留含义、语气和科学限定；不把禁词替换当文学质量。
- [文稿编辑](../../.agents/skills/earthstory-document-editing/SKILL.md)：重构难读文本，分开阅读稿与制作资料，维护版本和主张对应。
- [共同验收标准](editorial-rubric.md)：内容、听觉理解、科学准确性、系列承接，以及脱离制作资料的读者测试。

这些是供支持仓库技能的工具读取的文件，也可供编辑人工使用。它们不是已部署的多代理运行系统，不会自行联网、配音、出片或发布。是否自动发现取决于使用它们的工具；本次不声称已安装进任何个人技能目录。

## 采用什么，舍弃什么

采用独立读者测试、主张—证据追溯、修改后再核查、自然口语审读和声画分工。将这些方法写成适合中文科学纪录片的原创规则，而非拼贴上游指令。

不移植英文固定词数、营销号召、强制三幕比例、每十五秒一个钩子、学术论文模板或“禁词通过即质量通过”的做法。没有复制第三方技能正文、课程全文或专有文档处理代码。Anthropic 的 docx/pdf 许可尤其不能被当作整包开源授权；详见调查的逐项记录。

本项目的段落建议、文档分层和评分标准属于自己的编辑取舍，不能表述成 NPR、BBC、CDC、NIH、TED 或上游技能作者的规定、认可或合作成果。

## 验证边界

技能元数据可用标准技能校验器检查，但通过校验只说明格式合规。作品质量要看真实改写后的理解、事实保留和表达；第001集可作首个案例，后续应用还应检查不同题材，避免把行星形成的叙事顺序固化成全系列公式。
