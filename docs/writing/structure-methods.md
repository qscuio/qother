# 结构方法：先选理解路线，再选叙事技巧

用于新写、结构深改和定位“每句都懂，连起来不懂”。不替代[交稿流程](delivery-workflow.md)、[写作手册](narrative-craft.md)或[共同验收](editorial-rubric.md)。只读本次需要的方法；不是世界最佳结构全集，也不是按名气排列的模板。以下选择器、非虚构限制和中文小例是本项目的原创编辑改造；理论出处、作品案例与查阅范围见[来源与案例](structure-sources-and-cases.md)。

## 快速选择：观众究竟卡在哪里

- 不知道事情怎样发展：优先顺时＋必要机制。不要先打乱年代。
- 知道结果，不懂为什么：优先因果解释；因果尚未确定则选证据推理，不伪装成定论。
- 不懂“我们凭什么知道”：用证据 → 推理所需前提 → 能支持的结论 → 边界。
- 一个真问题有数条调查路径：问题调查；已知答案不必伪装成未解悬案。
- 多种过程交叠、时间跨度很大：编年跨尺度；若互相影响才考虑主题编织。
- 两种对象的差异是核心：对照，按同一比较维度交替，而不是先讲完甲的百科再讲乙。
- 眼前物件能引出历史：框架叙事或结果先行。没有可信当下场景就直接解释，不编参观、采样或见证。
- 现稿已经顺畅：保留。只有缺转折、缺回收等具体问题时才用三幕、五幕、起承转合等检查视角。

通常定一条主路线，在局部使用另一种组织法即可；复杂材料可以更多，但每次切换都要有理解收益。工作记录写一句“采用什么，因为观众需要什么；没有采用哪种容易误导的方案”。不要求每稿提交多套提纲供用户替作者选择。

## 基础结构库

### 1. 顺时与编年（chronological）
用途：追踪同一对象的变化、建立先后条件。前提：时间关系可靠，跨度和重叠可交代。操作：保留改变状态的节点，背景用概述连接；年代只定位，不负责解释。

反例：“先有氧，后来有复杂生命，所以氧直接创造了复杂生命。”先后不足以证明因果。边界：大量并行过程不能排列成全球统一阶段；不清楚的日期用范围。小例：先交代材料何时存在，再讲材料在什么条件下改变，不用连续“随后”代替机制。

### 2. 因果／机制链（causal）
用途：回答条件怎样产生结果。前提：每个连接有事实支持，能区分必要条件、促进因素和充分原因。操作：从结果倒查需要的前提，再按听众可理解顺序写；遇到多因素保留分支与反馈。

反例：把“产氧”直接接成“大气富氧”，漏掉消耗过程。边界：不确定历史不能被流畅因果链抹平；材料只有相关性时明确止步。小例：“释放的氧有一部分会被反应消耗。因此，能否积累，还要看供给与消耗的关系。”这是关系示例，不替代正片来源。

### 3. 问题调查
用途：让问题带着观众寻找材料，展示解释如何被修正。前提：问题真实、有可进入的证据路径，结尾能回答本篇承诺或明确余下未知。操作：每条材料改变问题的哪一部分；支线若既不支持也不限制回答，就移走。

反例：为普通解释凭空写“科学界争论数百年”，或先藏着关键定义制造谜面。边界：未知不等于意见各半；不要把边缘猜测抬成势均力敌的争论。小例：“岩石留下了什么记录？”可以引入证据；不能承诺“揭开地球全部秘密”。

### 4. 证据推理
用途：把“发生了什么”和“今天怎样知道”分开。前提：能说明观测与推断的连接、替代解释及证据局限。操作：给出证据对象、它在什么条件下支持何种判断，再收窄结论；可以先给结论再解释依据，但不能只摆仪器名。

反例：“发现一块古老岩石，于是知道整个地球当时的样子。”边界：局部样本不自动代表全球，模型重建不等于实录。小例：“这些遗存支持这里曾利用某种资源；仅凭它们，还不能知道所有人的日常食谱。”

### 5. 编年跨尺度
用途：在长时段发展中放慢一个关键过程，再返回大时间线。前提：尺度切换确有解释用途，日期、持续时间与画面压缩不混淆。操作：先说目前在哪个时间范围，再进入细节；返回时交代刚才是这一时期的局部过程还是另一个时段。

反例：从百万年变化切到数小时反应后，用“与此同时”把两者写成同一瞬间。边界：跨尺度不是任意跨时代蒙太奇；保持过程交叠。小例：地层中的长期记录 → 一个有依据的沉积机制 → 回到记录能覆盖的时段。

### 6. 对照／并置
用途：让共同尺度上的差别承担解释，避免抽象形容。前提：比较对象、指标、条件可比。操作：先立比较轴，再按该轴讲甲与乙；必要时解释哪些条件并不相同。

反例：以两地不同保存条件下的遗存数量直接比较人口；为戏剧效果把研究观点划成善恶双方。边界：并置只提出关系，不证明因果。小例：同一问题下比较两种生计组合，不把一种叫“落后”、另一种叫“必然进步”。

### 7. 主题编织（braided / thematic）
用途：让两条以上材料线互相补足，如过程史与认识史。前提：每条线独立可跟随，交点会改变理解。操作：用问题或共同对象换线；每次回来都推进，必要时短定位。没有交互收益就分章讲。

反例：每段在宇宙、恐龙、现代人之间跳转，只靠“同样震撼”连接。边界：相邻剪接不等于同时发生；主题相似不证明历史联系。小例：地层怎样形成／研究者如何读取地层，在“记录缺失”处相交，而不是编造一位贯穿全片的科学家。

### 8. 框架叙事与环形照应
用途：以当下观察、真实档案问题或中心物件进入过去，再回来显示理解变化。前提：框架材料真实，回归提供新增认识。操作：开端提出可观察对象，中段解释其来路，结尾回到同一对象但不重复开头评价。

反例：凭空编“我们站在荒原上”，末尾再说“荒原诉说亿万年”。边界：环形是阅读效果，不是自然历史真的回到原点；没有新认识可直接结束。小例：从岩石中的一层纹理进入形成机制，再回到这条纹理能与不能告诉我们的内容。

## 戏剧结构：用于检查，不替事实编情节

### 三幕
可借“建立情境／发展变化／形成结果”检查中段是否停滞；有真实目标、障碍和结果的人物研究史更适合完整戏剧弧。前提是材料本来支持变化，而非作者给材料加冲突。科学解释也可以是“现象／机制／适用范围”，但这是本项目借用的工作分组，不等于经典戏剧三幕的原定义。

反例：给地球安排愿望，令撞击成为反派，再以生命出现写胜利。边界：无固定1:2:1、分钟数或转折位置；短解释不必三段，结论未定不能强行大团圆。

### 五幕
可借更多阶段检查长篇中段的推进，例如真实调查中的起点、困难升级、关键变化、后果、收束。前提是确有足够不同的变化，且每阶段不是上一段换词。Freytag的戏剧金字塔与当代编剧的五幕教学不完全等同，不混成唯一权威步骤。

反例：只为凑五幕，把同一机制拆五次、把局部未知造为危机。边界：信息简单就不增幕；第五幕不保证历史结束。不能把一位编剧认为结构普遍有效的主张写成科学定律。

### 起承转合
可借“引入／展开／换一角度检验或推进／收束”看篇章是否只有铺陈。前提：“转”有材料依据，“合”回应真正主题。它来自诗文布局，不等于四个固定段落，也不是天然无冲突或必有反转的东方万能模式。

反例：事实本来连续却每第三段硬加“然而”；末段突然升格成人类命运。边界：转可以是尺度、证据或认识的推进；没有必要换向时，不制造相反论点。

### 英雄之旅（hero's journey）
可在有可靠人物材料的探险、研究或传记中，检查出发、经历、返回后的变化。前提：真实经历与来源支持，不用神话模型替代史料。它是对神话模式的理论与创作资源，不是科学非虚构默认结构。

反例：把元素写成接受召唤的英雄，令自然选择“战胜困难走向人类”。边界：不强塞导师、拒绝召唤、低谷、胜利或救赎；不能为角色弧编内心、对白、唯一功臣或恶人。材料只有无主体机制时直接不用。

## 信息如何展开

### 倒序、结果先行与中途切入
- 结果先行：先给结果，再回到成因。适用已知终点、成因才有价值；前提是回溯有可靠依据。反例是结尾才补回能改变开头结论的限定。
- 逆时序（reverse chronology）：段落沿事件先后反向走；每次回退须定位，且能帮助理解记录层次或因果回溯。前提是收益大于时间负担；不等同于科学上的可逆过程。材料已经难懂时优先顺时。
- 中途切入（in medias res）：从一个已在发生的变化进入，尽快补足对象、位置和必要前因；适合有可信可跟随事件。前提不是“观众越迷惑越好”。远古过程不可虚构在场感官；不要迟到第三段才交代“它”是什么。

### 悬念、好奇、惊奇与信息差
悬念关注接下来会怎样；好奇追问已见结果从何而来；惊奇要求修正先前预期。它们是可选择的观众反应，不是每稿必备装置。历史结局已知仍可解释条件，不必假装结局未知。

先确认读者有足够信息形成一个真实问题。可以延后答案，不能延后理解答案必需的定义、证据身份、风险或限定。若用反直觉事实，先确认反直觉针对谁，不编造“所有人都以为”。角色当时所知、观众此刻所知、今日研究所知分开记录；不能把今日知识塞回历史人物的心里。

反例：“这个秘密将颠覆一切”，后文只是常识；或隐藏样本局限让假说看似已经被证实。没有有价值的信息差就明说。

### 铺垫与回收
前提是前段材料后面真正承担解释、判断或认知变化。先给必要线索，回收时补充关系；既能独立理解，又因再出现而更有意义。为重要承诺记录回收位置，未回收就补足或缩小开头；无须每个小细节都回收。

反例：开头提岩石、结尾再提岩石，但意思未变；为了回收而捏造两件东西的历史联系。边界：不把相关性当命运伏笔，不为完美闭环删反证。

## 从结构落到顺畅中文

1. 解释梯度：按“已知对象 → 此次变化 → 必要机制／证据 → 新认识”检查依赖，不规定每段照此写四句。术语在有指向时出现；专业观众不必绕回入门。反例是五个生词定义完才说它们为何有关。
2. 叙事与说明：变化用叙述推进，不可见机制用说明补足，长时段用概述压缩。前提是有可支持的内容；不把“展示，不要讲述”绝对化。反例是为逃避说明而编现场，或在每次变化前插百科讲义。
3. 段际承接：先圈前段落点、后段起点，写出真实关系。找不到关系就改顺序或删支线；有关系却缺前提就补解释。反例是只加“在这样的背景下”。同一对象可从已知引出新信息，但不把句句尾词机械重复到下句开头。
4. 句段节奏：把承重条件和结果放到容易听出的地方；停顿用于消化变化，长句用于保住紧密关系。前提是先把意思写对。反例是每句八个字、每段三句、所有段尾都感叹。按[交稿流程](delivery-workflow.md)检查动宾、指代、修饰距离与省略，再做文本口读预审。

小诊断：“岩石记录了变化。生命走向复杂。大陆也在移动。”问题不是缺华丽转场，而是三件事之间关系未给出。若来源不能连起来，收窄本段只讲记录；若来源能支持关联，明确是哪条记录支持哪项变化。不能靠“由此”“命运”“悄然”把空隙抹平。

## 交给镜头设计的接口

只在本次授权包括声画设计时，向镜头技能交已有净稿版本／段落定位，以及必要的五项说明：段落功能；观众进入和离开时知道什么；证据对象与主张ID；时间／尺度／模型身份；不得提前揭示或画成确定事实的内容。沿用既有伴随文件，不另造每句强制表格。

声画交接的信息量硬门槛：每个承担解释的镜头都须能指认可见的新关系、变化或机制，并回答“本镜解释什么，删去会损失什么”。纹理漂移、泛推拉和气氛变化本身不算解释；若没有信息收益，就补出有依据的可见关系，或合并、删除该镜，不能只换运镜名称。允许有具体定位、消化或情绪过渡用途的镜头，但须限制其时长与连续出现的比例，并说明对理解的作用；不设脱离题材的统一百分比。开头不能全由气氛镜构成，须及时建立可跟随的对象与本段要解释的变化。

镜头可承接比较、示意、定位和留白；不能靠漂亮画面补一个正文和来源都不存在的因果。镜头反馈暴露解释缺口时返回写作层，在授权范围内修订并重核；冻结稿未经准许不改，仅报告适配问题。旁白无需逐字描述镜头，镜头也不能把旁白的“可能”演成唯一历史。没有实际声画材料只验收文本接口，不声称已验证成片。
