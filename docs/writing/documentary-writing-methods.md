# 《地球往事》中文纪录片旁白：写作方法调研

核验日期：2026-10-09。用途：为系列建立原创写作流程，不是安装第三方 agent 或复制他人课程。以下资料是机构公开指南或专业作者的实践文章；没有把它们称作开源技能包。来源建议与本系列自行制定的编辑规则分开标注。

## 核心结论

先写一段能顺畅讲给人听的故事，再拆镜头。把科学准确性做进句子和证据台账，不要让每句旁白都承担审稿批注。现稿最值得保留的是事实边界和证据索引，最应改变的是知识出现的顺序、句子承载量，以及口播和制作说明混排。

## 八个可核验来源

### 1. NPR：写给耳朵，每句聚焦一个意思
- 标题：Need to write a toast or a script? Here are 7 tips to let your voice shine through
- 作者：Abē Levine；2023-02-17。NPR 原创、NCPR 正式转载。
- 链接：https://www.northcountrypublicradio.org/news/npr/1156597697/plus.npr.org/throughline
- 核验：已打开全文，正文确认 NPR 作者、来源及建议。
- 可迁移：用熟悉的日常词；避免一句向多个方向展开；写前先说一遍，写后再念一遍；根据对象调整语气。
- 不迁移：文章针对英文的缩写和夸张表演练习，不直接变成中文科普的文风规定。无需为口语感添加“我猜”“有点像”等无意义填充词。

### 2. CDC：Audio Script Writing Guide
- 链接：https://tools.cdc.gov/medialibrary/docs/AudioScriptWritingGuide.pdf
- 核验：已打开6页官方PDF，修订标记为2011-04-19。
- 可迁移：旁白应自然；线性推进；每句一个核心意思；句长需要变化；删掉听众看不见的括号补充；把符号、缩略语写成明确读法；自己与他人试读，检查卡顿、歧义和气口。
- 不迁移：英文“25词以内”只是该指南的经验值，不能换算成中文25字硬指标。字体和开场模板属于其生产环境，不必照搬。

## 对现稿的编辑诊断

检查对象：第001集《尘埃聚成一颗行星》工作稿1.1。

1. S01刚建立尘埃到行星的期待，S02—S04即转入两个年龄数字、年代层级及四宙名单；物理过程到S05才继续。建议先维持形成过程，地质时间尺只在定位确有必要时简短出现，完整层级移入附页或其他专门段落。若系列明确要求本集教授层级，则保留但重新安放。
2. 15秒网格虽然注明是比较预算，仍把完整意思切成24个同尺寸单元。初稿应按变化和解释需要成段，定稿后才配时、拆镜；不要通过硬提语速守住格子。
3. 多句是在给制作团队防错：“不能把整个过程想成……”“不能直接照搬……”等。需要观众理解的科学限制仍应说；仅用于防止画错的禁令放导演说明。不要机械删掉所有否定句。
4. 后半段年龄与证据很重要，但应由自然问题引入：这些过程过去了几十亿年，今天凭什么知道？避免先报答案，后面再反复解释答案为什么不是准确生日。
5. “共同参与”“明显分层”“增长和重组”等概括词过密。具体动作先行，概括术语随后确认；不可为了生动新增没有证据的速度、触感、现场声或目击者视角。

## 本系列原创编辑规则（编辑推论，不冒充来源原话）

- 一段只完成一个认知变化。段落可比一句长，但听众应能复述“刚才发生了什么，为什么”。
- 优先使用“对象—动作—结果”：颗粒碰撞，部分黏住；天体变大，引力影响增强；撞击把运动能量转成热。只在证据支持时使用“因此”“所以”。
- 现象先出现，术语后命名；术语若不再使用且不帮助理解，可不念。不得把必要术语换成误导性比喻。
- 中文少用连续“的”字结构、多个“在……中”、抽象动词套叠。允许长短句交替，靠关系和气口分句，不设机械汉字阈值。
- 转场回答观众刚产生的问题，而不是每段重新宣布“接下来我们将”。悬念来自真实的因果缺口，避免“惊天秘密”“竟然颠覆一切”。
- 不确定性贴近具体主张：说清稳定结论与待解决环节。一个同类限制可完整说明一次，后续保留必要的“约”“可能”等精度词；若主张变了，必须重新限定，不能用开头免责声明覆盖全片。
- 净旁白单独可读，不插入镜头号、导演禁令、来源URL或事实审核批注。导演稿另存画面、标注及节奏；证据台账保留逐项主张、来源和限定条件；三者用稳定ID相连。
- 节奏先服从意义。没有真人或TTS试读，就只给估计，不写“已验证六分钟”。

## 两个局部示范（仅优化表达，不是事实新证据）

### 示例A：把抽象过程改成直接动作
原句（S12）：
“运动中的能量，也会转成热。一次次撞击改变表面和内部的温度，较大的撞击能够造成广泛熔融，让岩石失去原来的坚硬形态。”

建议：
“天体撞在一起，一部分运动能量转成了热。撞击足够大时，大范围的岩石会熔化。”

保留：撞击加热，大撞击可造成广泛熔融。没有暗示所有运动能量都转成热，也没有新增温度或历时。需沿用原E06核查。

### 示例B：分开对象，保留条件
原句（S14）：
“在能够流动的环境中，密度较大的富铁金属向深处迁移，逐渐汇入地核；相对较轻的硅酸盐物质，构成外围的主要部分。”

建议：
“当内部物质能够流动，密度更大的富铁金属便向深处迁移，逐渐汇成地核。相对较轻的硅酸盐物质，主要留在外层。”

保留：可流动条件、密度差、富铁金属与硅酸盐的区分；“主要”不可删。后句可在观众看懂分层后解释硅酸盐，不应把所有外层一律说成今天的地壳。需沿用原E06核查。

## 改写验收

1. 不看画面，能跟上主要因果；需要图示的空间细节可由画面承担。
2. 单独读净旁白，没有误把制作批注念出口的风险。
3. 非专家能复述主要过程；未真正测试时标为待测试，不能声称通过。
4. 每条科学主张有来源；风格编辑后再次核对限定词、数值、时间、因果。
5. 多余的术语名单、重复回顾、空洞悬念和防错口令已移除或安放到正确文档。
6. 阅读节奏只做文字层面的预审；实际配音与时长验证另行授权。
