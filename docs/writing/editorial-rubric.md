# 地球往事文稿验收

这是一套写作与编辑共同使用的验收方法。评分用于定位问题，不代替事实核查，也不以凑分替代判断。

## 先过硬门槛

- 没有新增无来源的事实、引语、人物内心或具体目击情节。
- 改写后的年代、因果、确定性与来源实际支持范围相符；必要的模型或不确定性限定仍在旁白中。
- 原来源 ID 和制作标识可追溯；新段落有可核对的主张与来源对应。删掉的内容留有记录，不让旧分镜被误认为新稿最终版。
- 主稿、制作说明与结构化文件的版本／同步状态真实；无“已配音／已渲染／已试读”等未经执行的声明。

任何一项失败，先修复或明确阻塞，不用总分掩盖。

## 前后比较

按任务范围选择维度。局部句段没有完整开头结尾、声画设计或系列上下文时，对应项标“不适用／未检查”，不打分，也不假装完成整集验收。下面的交付线只适用于具备相应上下文的完整单集。

对同一段或同一集比较，每项 0—2 分：0 表示明显失败，1 表示局部成立但仍需修改，2 表示全稿基本成立。为每项写一条具体文本证据和一个可改进处；不只报数字。评价内容是否更好理解、更值得听，而不只统计禁词、句长和标题数。

| 维度 | 2 分意味着什么 |
| --- | --- |
| 核心问题 | 读完开头知道要理解什么，结尾确实回答；不用空洞悬念拖延。 |
| 叙事推进 | 各段带来状态变化、原因或证据；调换顺序会损害理解，没有名词清单堆砌。 |
| 内容与表达 | 事实经过选择和组织，能形成一个可复述的认识；具体过程有画面与节奏，既无抽象套话，也不是机械短句提纲。 |
| 口语清晰 | 单句主要意思明确，指代清楚，术语在现象之后解释，朗读不频繁回头补读。 |
| 科学分寸 | 观测、解释与未知的区别可理解；既不编造确定性，也不以大量模糊词冲淡已知结论。 |
| 阅读页面 | 连续读旁白无需跨越制作字段；标题数量和段落长短服务内容，链接可用。 |
| 视听分工 | 画面提供过程、尺度或证据，旁白提供理解，不逐镜复述画面；示意与真实素材有清楚边界。 |
| 系列承接 | 观众不依赖未讲过的术语；不抢讲下一集；结尾留下真实的下一问题。 |

建议交付线：各项至少 1 分，核心问题、内容与表达、科学分寸达到 2 分。这个线是项目工作约定，不是研究证明的普适量表。

## 脱离制作资料的读者测试

只给主稿，不给作者解释或预期答案，请读者回答：

1. 本集最主要的问题是什么？结尾怎样回答？
2. 哪两处变化之间的关系最难理解？
3. 哪个说法属于解释模型，哪里仍不确定？如本稿没有适用案例，说明即可。
4. 哪句话需要重读？哪个名词出现得太早？

把误读定位到正文并修改，而不是只补写作者解释。独立评审可由另一位编辑或一个只看到主稿的评审实例完成；区分真人测试、独立文本评审、作者自检，不能混称。

## 计时和制作对齐

先定旁白的理解顺序，再按段落估时。记录估时依据、停顿和图解留白；最终时长等待真实试读。既有 24×15 秒之类网格可以保留作版本比较，但新稿若未重新对齐，应明确说明，不把“总长相同”当作镜头匹配证据。
