# 地球往事文稿验收：看读者获得什么

先核事实，再判断作品。评分、禁词统计和技能格式校验都不能代替阅读；不设用总分抵消事实错误的交付线。只检查本任务有材料支撑的范围，缺少全片、声画或系列上下文就标“不适用／未检查”。

执行顺序见[交稿流程](delivery-workflow.md)；本页负责判定，不重复要求生成另一套流程材料。

## 事实与交付硬门槛

- 无新增无来源的事实、引语、内心或目击情节；因果、条件、范围、数值、否定、归属和确定程度与来源一致。
- 区分观测、模型和未知，必要限定在旁白内；美化不能把假说升级为事实。
- 开头许诺解释的问题已回答或收窄；无需要读者自行补造的因果步骤。对象与代词不误指，概括没有改变材料来路、阶段重叠或模型身份。
- 来源 ID、主张映射和制作标识可追溯；移删内容有记录。改稿后不得自动沿用旧核查结论。
- 净阅读正文不混入写作流程、审稿口令或来源管理提醒；科学限定自然保留，只有理解题材确有需要时才解释其含义。
- 主稿、分镜和结构化资料的版本／同步状态真实。未做真人试读、录音或渲染，就不声称已经做过。

任一硬门槛失败，不称完成稿；先修复或明确待核阻塞。独立审阅指出的问题须在修订后复核，不能沿用初稿评语。短样段不要求生成全片伴随资料；没有授权不能以验收为由扩写或改下一集。

## 编辑判断：给证据，不报空泛好评

对适用维度标“成立／需修订／未检查”，引用具体句段，说明理解效果及剩余问题。

- **立意与选材**：读完能说出核心关系；细节承担解释而非仅装饰，反证和限制未被删掉。
- **信息与推进**：读者具备下一步所需前提；相邻段有实际关系，时间、原因和模型没有混成一条线。
- **视角与详略**：讲述者所知边界清楚，关键变化有空间，背景不淹没重点；不编造现场或自然目的。
- **语言与余味**：动作、指代和词义准确，句势服务意义；具体细节、照应或形象表达带来理解而非空洞感叹。
- **听读与页面**：可以连续读，术语有所指；制作字段不侵入正文，标题与链接帮助寻找内容。
- **声画与系列（有材料才检查）**：画面与旁白分工明确，示意不冒充实录；不依赖未讲术语、不抢答后集。

诊断的最低单位是“哪里 → 造成什么困难 → 用什么改动解决”。不强制每项找毛病；已经好的文字说明保留理由。涉及中心认识、次序或解释缺口的是结构修改，不能只给词语替换建议。

## 初读：复述、推断、找理解断点

让未看作者大纲、预期答案、修改理由的人只看正文。按本次最重要的理解风险选一两个问题即可；记录实际回答，不代答、不用引导问题喂结论：

1. 用自己的话说这段／这篇使你理解了什么。哪些变化相连，怎样相连？
2. 哪个细节最有用？删掉它，你会少理解什么？
3. 哪一处需要重读，缺的是前提、指代、机制还是时间定位？
4. 哪个结论有条件或属于模型？原文允许你确定到哪里？
5. 提出一个只需迁移文中关系即可回答的近邻问题，请读者解释推理；若文本不够，允许回答无法判断。

近邻问题示例：月光段可问“若光走的路更长而速度相同，延迟怎样变？”；模型段可问“文中模型能否证明地球一定经历同一路径？为什么？”这检查关系理解，不是背原句，也不额外考专业知识。

编辑把误读定位回正文，修正后用等难的新问题复查，避免只训练读者记答案。可做删细节、交换相邻段的试验；顺序可互换不必然是缺点，速查说明本就可能适合并列组织。

## 盲评及口读的证据边界

独立模型评审只给净稿和最低任务背景，不给作者打算获得的答案、偏好的版本或前轮结论。比较两稿时隐藏版本身份并改变顺序，要求引用具体文本及指出取舍；单次偏好不能证明文学效果。作者自检、独立模型文本评审、真人阅读与真人试音分别标明，不能混称。

只有文本时可作“文本口读预审”，找回读、气口和歧义；不能声称听到了真实声音。字数估时须说明依据并留出停顿与图解空间，最终时长待实际试读。十五秒旧网格可作比较，不构成新稿逐镜匹配证据。

## 技能的小规模功能题

复测技能时用隔离样段，不能顺便重写正片。[跨题材用例](tests/cross-topic-cases.json)保存宇宙、地球史、人类史三组限定材料与可观察不变量；运行方法见[测试说明](tests/README.md)。没有标准措辞答案。以下是额外的局部检查类型：

- **结构题**：把数字与结论平列的月光材料写成短旁白。观察是否建立理解顺序而非只删形容词，数值近似是否保留。
- **保义题**：精修带模型身份、条件和未知的科学段。检查读者是否仍能区分可能路径与唯一历史；缺失机制是否诚实指出。
- **克制题**：给已清楚且含必要限定的段落，只要求审阅。观察是否保留好段、避免改文件，且不给虚构的全片成绩。
- **反模板题**：给没有人物、冲突或反转的说明材料。观察是否仍能写清楚，不硬造设问、三幕、情绪或比喻。

功能测试的结果只支持实际观察到的行为，不证明未来所有稿件都自然优美。格式校验和既有回归检查另行报告，不合并成文学质量分。
