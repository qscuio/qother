# 把故事写作方法用于事实叙事

这里的方法用于内容开发与深度改稿。它们借鉴公开小说技能的工作方法，以本系列的事实边界重新编写；不采用虚构小说的创作许可。

## 1. 找到这一集独有的认识

先用一句普通话说明：观众读完会理解什么变化，以及原先不容易看见的关系。主题如“地球形成”只是范围，不能代替认识。

当材料有几种合理组织方式，可比较两种简短方案。例如按物理过程走，或从今天的证据回溯过去。比较哪一种更容易建立必要知识、让证据自然出现、避免提前回答后文；不要为制造悬念故意隐瞒理解所需的事实。选择后再展开，不必为每次小改写走完整套规划。

## 2. 写因果纲，同时安排读者知道什么

用几行工作笔记记录每段的起始状态、实际变化、支持该变化的证据、结果，以及它怎样接到下一段。它是帮助思考的工具，不是要放进旁白的表格。

自然过程没有人物的意图。小说里的“目标—阻力—选择”不能直接搬过来：行星并不努力成为地球，演化也不等待人类。应写条件怎样改变可能性、材料怎样运动、证据能解释到哪一步。

为每段再问两句：读者到这里已经知道什么？要理解下一步，还缺哪个对象、尺度或机制？把术语放到它有具体所指的时候。不要把未来计划当作观众已听过的内容；检查实际前集正文，而非只读大纲。

时间先后、因果关系、解释模型分别核对。证据只支持先后时，不能用“因此”升级成因果；真实的未知可以保留，但不夸成惊天谜团。每段需要进展，不必每段反转或留下钩子。

## 3. 先试一小段声音，再扩写

如果语气尚未确定，先用同一份事实材料写两三段连续正文，检验解释密度、意象和节奏，再扩成全稿。已有接受的原创好段落时，以它校准声音；没有时不要宣称风格已经获认可。

具体不是感官词堆积。一个有来源的动作、尺度差或材料变化，常比几句“壮阔、神秘、震撼”更有画面。需要补充细节时，先找证据；不能为了生动编造温度、颜色、速度、声音、对白、见证者或心理活动。

“展示而非解释”不适用于所有句子。纪录片必须解释看不见的机制、压缩极长时间。判断一句解释是否必要：它是否让观众看懂刚才的变化，或准备理解下一步？必要的解释写清楚，空泛的结论换成实际内容。

## 4. 诊断与重写分开

先找最高影响的问题，再动笔。一个有效诊断包含：具体句段位置、问题证据、对读者理解的影响、最小有效修复。优先修事实与因果，再补缺失解释，然后整理段落，最后打磨语言。若局部修改救不了结构，重写整段；别用换词掩盖。

句法计数、重复词和抽象词只能提示值得检查的地方。没有感官词配额、固定段长、强制短句、禁词得分或章末悬念配额。“约”“可能”“目前证据”等有科学作用的词必须保留。自然中文允许平实解释、节奏舒展和必要重复，不追求刻意粗糙来冒充人味。

## 5. 初读反馈必须看见具体问题

初读评审只看正文，不看作者大纲、预期结论和制作资料。请按阅读顺序记下第一处失去方向、想跳过、术语无所指或仍想追问的位置；每条反馈引用短句或定位段落，再解释原因。读完后复述中心问题和关键变化。

模型模拟必须标作模拟初读；几个不同角色不等于几个真人。初读反应与事实核查分开，不能凭“流畅”断言准确。针对反馈修正文，再复核改动过的主张、来源、数值、限定与因果。改稿后原有核查结论不能自动视为仍然有效。

## 方法出处与取舍

- [wgwtest/novel-writing](https://github.com/wgwtest/novel-writing)：借因果与信息顺序；其技能排除非虚构，本项目只迁移一般方法，不直接调用它写史实。
- [liuxiao20051106-prog/novel-writer-skill](https://github.com/liuxiao20051106-prog/novel-writer-skill)：借事实记录、定位证据的评审；不把统计诊断当文学质量。
- [haowjy/creative-writing-skills](https://github.com/haowjy/creative-writing-skills)：借结构诊断与行文修改分层；不把角色模拟当真实观众验证。
- [danjdewhurst/story-skills](https://github.com/danjdewhurst/story-skills)：借隔离的初读反馈；不引入短片不需要的庞大实体系统。
- [renky1025/agent-skills](https://github.com/renky1025/agent-skills)：借从核心概括展开和短样段定声；不把三幕和人物弧当自然史规律。
- 中文长篇实践补充了“已接受正文与未来计划分开”“前集原文与语气样段校准”“确定性检查不能代替文学判断”。完整出处、许可与可读范围见[小说技能调查](story-novel-skills-survey.md)和[中文专项](chinese-novel-workflows.md)。

小说的“正史”是创作者接受的设定；纪录片即使已经接受的稿件，也必须服从外部证据。这是两种写作之间不能跨过的边界。
