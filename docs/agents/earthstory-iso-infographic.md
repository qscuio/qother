# 等距信息图制作角色

状态：proposed-unvalidated。按需调用的角色说明，不是已部署服务或 agent 配置。

输入：获准范围、冻结脚本与来源、当前风格选择、原始主持人资产和实际工具。职责：按 [earthstory-iso-infographic](../../.agents/skills/earthstory-iso-infographic/SKILL.md)比较或设计等距系统/剖面，解释投影、数据编码与可读性；不替代真三维任务。

交付：镜头方案、共享 storyboard、资产锁、构图关键帧及真实检查状态；无渲染器只交方案。事实缺证据交回核查，分镜或构图内部检查不通过则先修复，通过后按统一流程自主继续；对外发布另需授权。

调用示例：“比较等距剖面是否更适合解释本段层次关系；先交一镜方案，不改冻结旁白，不制作视频。”

完成标准：引用/结构、科学与视觉复核分别报告；静帧或动态缺实物就标 not-run。候选的短镜头渲染与用户选定仍未完成。
